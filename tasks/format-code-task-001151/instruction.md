The Go SDK's Struct.Diff API is used by the noms diff renderer to compare a previous value with a current value. When schemas evolve, a field present only in the current struct must be reported as added under its current field name, while a field present only in the previous struct must be reported as removed under its previous name. These events must be emitted in lexical field order alongside unchanged and modified fields. At present, a leading or interleaved schema addition can be attributed to the wrong side, so callers either receive an incorrect ValueChanged event or the CLI tries to read a newly added field from the old struct and panics. Correct the public behavior without regressing ordinary modified fields, removals, or nested structs. The cmd/noms/diff Diff function must render additions and removals using the value from the corresponding struct, must not panic for these schema changes, and must preserve the existing path and textual diff format when a changed struct is nested inside another value.
