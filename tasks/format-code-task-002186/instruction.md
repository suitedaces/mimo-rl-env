I want a stateful cache storage package that exposes `data_layer.DataLayerInterface` and two implementations: `data_layer.MemoryLayer` and `data_layer.RedisLayer`. A caller should be able to construct either implementation with `&data_layer.MemoryLayer{}` or `&data_layer.RedisLayer{}`, call `Init(conf *config.CacheConfig, prefix string) error`, then use `BatchKeyExist(ctx context.Context, keys []string) (bool, error)`, `KeyExists(ctx context.Context, key string) (bool, error)`, `GetValue(ctx context.Context, key string) (string, error)`, `BatchGetValues(ctx context.Context, keys []string) ([]string, error)`, `CleanCache(ctx context.Context) error`, `DeleteKeysWithPrefix(ctx context.Context, keyPrefix string) error`, `DeleteKey(ctx context.Context, key string) error`, `BatchDeleteKeys(ctx context.Context, keys []string) error`, `BatchSetKeys(ctx context.Context, kvs []util.Kv) error`, and `SetKey(ctx context.Context, kv util.Kv) error`.

For `MemoryLayer`, `Init` should create an in-process TTL cache sized from `CacheConfig.CacheSize` and store TTL behavior from `CacheConfig.CacheTTL`. In a concrete session, after `SetKey(ctx, util.Kv{Key: "user:1", Value: "alice"})`, `KeyExists(ctx, "user:1")` should return `true, nil` and `GetValue(ctx, "user:1")` should return `"alice", nil`. After `BatchSetKeys(ctx, []util.Kv{{Key: "user:2", Value: "bob"}, {Key: "user:3", Value: "cara"}})`, `BatchKeyExist(ctx, []string{"user:2", "user:3"})` should return `true, nil` and `BatchGetValues(ctx, []string{"user:2", "user:3"})` should return `[]string{"bob", "cara"}, nil`. If any requested memory key is absent or expired, `GetValue` should return an error with message `cannot get item`, `BatchGetValues` should return an error with message `cannot get items`, and existence checks should report false without treating a miss as an error. `DeleteKey`, `BatchDeleteKeys`, `DeleteKeysWithPrefix`, and `CleanCache` should remove matching memory entries and return nil.

For `RedisLayer`, `Init` should use `CacheConfig.RedisConfig`: create a Redis client from options when the mode is options, otherwise use the supplied client, then load the Redis scripts needed for batch existence checks and prefix cleanup. In a concrete session against Redis, after `SetKey(ctx, util.Kv{Key: "session:1", Value: "token"})`, `KeyExists(ctx, "session:1")` should return `true, nil` and `GetValue(ctx, "session:1")` should return `"token", nil`. After `BatchSetKeys(ctx, []util.Kv{{Key: "session:2", Value: "two"}, {Key: "session:3", Value: "three"}})`, `BatchKeyExist(ctx, []string{"session:2", "session:3"})` should return `true, nil`, and `BatchGetValues(ctx, []string{"session:2", "session:3"})` should return the stored string values in key order. `DeleteKey` and `BatchDeleteKeys` should delete the named Redis keys, `DeleteKeysWithPrefix(ctx, "session")` should remove keys matching that prefix, and `CleanCache` should remove keys under the initialized cache prefix. Redis command or script-load failures should be returned to the caller instead of being swallowed.
