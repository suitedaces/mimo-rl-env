I want a one-shot library helper `evaluate_condition_lingo(condition_lingo: Lingo, providers: Optional[ConditionProviderManager] = None, context: Optional[ContextDict] = None, log: Logger = default) -> None` that evaluates a TACo access-control condition document and only returns normally when access is allowed. If `providers` is omitted it should use an empty `ConditionProviderManager`, and if `context` is omitted it should evaluate with an empty context dictionary. For a valid condition document whose evaluation succeeds, such as a document parsed by `ConditionLingo.from_dict(...)` whose `.eval(...)` returns `True`, the helper should return `None`; calling it again with the same condition, providers, and context should produce the same success result apart from logging and any provider reads performed by the condition itself. For an empty or otherwise falsy `condition_lingo`, it should also return `None` without attempting condition evaluation.

I also need a public `ConditionEvalError(message: str, status_code: int)` exception for denied or malformed evaluations. If the parsed condition evaluates to `False`, `evaluate_condition_lingo(...)` should raise `ConditionEvalError` with message `Decryption conditions not satisfied` and HTTP status `403`. Invalid grammar should raise status `400` with a message beginning `Invalid condition grammar:`, invalid condition values should raise status `400` with `Incorrect value provided for condition:`, missing context variables should raise status `400` with `Missing required inputs:`, invalid context-variable data should raise status `400` with `Invalid data provided for context variable:`, unverifiable context-variable authentication should raise status `403` with `Context variable data could not be verified:`, missing chain connectivity should raise status `501` with `Node does not have a connection to chain ID <id>`, failed return-value processing should raise status `400` with `Unable to evaluate return value:`, and other condition evaluation failures should raise status `400` with `Decryption condition not evaluated:`. Any unexpected exception should be converted into `ConditionEvalError` with status `500` and a message that includes the exception class name and message.
