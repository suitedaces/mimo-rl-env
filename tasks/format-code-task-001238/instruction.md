I want the Go media title translator to expose `Translate(name string) string` so release-style media filenames can be turned into clean display titles. For `Translate("Godzilla.2014.720p.BluRay.x264-LEONARDO_[scarabey.org].mkv")`, it should return `"Godzilla"`. For `Translate("Godzilla 2014")`, it should return `"Godzilla"`. For names without a year or season/episode marker, it should still replace dots with spaces, remove bracketed release-group text, remove the tokens `720p`, `1080p`, `x264`, `BluRay`, `mkv`, `avi`, `mp4`, `(`, and `)`, trim surrounding whitespace, and return the cleaned string; for example `Translate("[Group]Plain.Title.1080p.mkv")` should return `"Plain Title"`. It should also stop the title at a four-digit year or an `SxxExx` episode marker, so `Translate("Example.Show.S02E03.1080p.mkv")` returns `"Example Show"`. The function should accept any string input, including an empty string, without returning an error or panicking; `Translate("")` should return `""`. Calling it multiple times with the same input should produce the same output and should not perform filesystem, network, or other external side effects.
