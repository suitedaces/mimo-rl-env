I want the `pluginval` command-line tool to support a `--strictness-help [level]` mode that prints which validation tests are included at a given strictness level without starting plugin validation. Running `pluginval --strictness-help` should default to level 5; running `pluginval --strictness-help 3` should use level 3, and levels outside 1-10 should be clamped into that range.

The command should write to stdout in this format: first `Tests at strictness level N:`, then a blank line, then one line for each registered test whose strictness level is less than or equal to `N`, sorted by strictness level ascending. Each test line should start with two spaces and the test title; if the test provides a description for that level, append `: ` followed by the description. Finish with a trailing blank line. The command should exit successfully with code 0 after printing the list, and `pluginval --help` should include `--strictness-help [level]` with a short description of this mode.
