I want the django-tables2 template library to provide a `{% render_table %}` tag for Django templates. After `{% load django_tables2 %}`, `{% render_table table %}` should resolve `table` from the template context, accept a `django_tables2.Table` instance, and return the rendered HTML from that table's configured template name. The tag should also support `{% render_table table "custom.html" %}` and render with the explicit template name instead of the table default, and the second argument should be allowed to resolve to a list or tuple of template names using Django's normal first-existing-template selection.

The rendering should use the current request from the template context when rendering the table template, and it should call the table's `before_render(request)` hook before producing the HTML. Template columns rendered inside the table should be able to see the surrounding template context, so a `TemplateColumn` can use values that were available where `{% render_table %}` was invoked. Passing a Django queryset such as `{% render_table user_queryset %}` should create a table for the queryset model and render the queryset rows. Passing any value that is neither a table nor a queryset should raise `ValueError` with a message like `Expected table or queryset, not dict`. Rendering with the same table, request, and template context should produce the same HTML and should not replace or mutate variables in the caller's template context.
