I want the `Player` game state object to make human discovery of bases part of normal time advancement. In a session like `pl = Player(cash=0, difficulty=diff)`, after the world has completed bases and `pl.give_time(time_sec, midnight_stop=True)` advances time while the player is no longer in the global grace period and the base's own grace has expired, every eligible completed base should roll once per human group using that base's current detection chance scaled to the elapsed number of seconds. If a group wins the roll, that base should be removed from its location, the player's CPU totals should be recalculated, the game should pause, and a red discovery message/log entry should identify the base, base type, location, and discovering group.

The discovery consequences should update observable state. The discovering group's suspicion should increase by its configured per-discovery amount, `pl.last_discovery` should become the discovered base's location, and `pl.prev_discovery` should retain the prior recent discovery location; if multiple bases are discovered in the same tick, two of their locations should be selected as the most recent and previous discovery locations. A base should not be eligible for human discovery while global grace is active, while its own construction grace is still active, or after it has already been selected for maintenance destruction during the same tick. A completed base that is not discovered during `give_time` should remain in its location and should not create a discovery log entry or increase any group's suspicion.
