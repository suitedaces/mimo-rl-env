I want `mlx.optimizers.MultiOptimizer(optimizers, filters=[])` as a stateful optimizer wrapper that lets me route different parameters in one parameter tree to different optimizer instances. The constructor should take a list of optimizer objects and a list of predicate callables, where each predicate receives the flattened parameter path and the array value; there must be exactly one fewer predicate than optimizers, and constructing it with any other count should raise `ValueError`.

`MultiOptimizer.init(parameters: dict)` should split the parameter tree by the predicates and initialize each wrapped optimizer only with the parameters assigned to it, using the final optimizer as the fallback for anything that did not match an earlier predicate. `MultiOptimizer.apply_gradients(gradients: dict, parameters: dict)` should split the gradient tree the same way, call each wrapped optimizer, and merge their returned parameter updates back into one tree with the original parameter paths. For example, with `[Adam(0.001), SGD(0.1)]` and a filter `lambda name, weight: weight.ndim > 1`, matrix weights should be updated by Adam while 1D bias parameters should be updated by SGD in the same call.

The `state` property should expose `{"states": [optimizer.state, ...]}` in optimizer order, and assigning to `state` should load each wrapped optimizer state from that list. Assigning a state object without a `states` list of the right length should raise `ValueError`. The `learning_rate` getter should return the first wrapped optimizer's learning rate, and setting `learning_rate` should assign the same value to every wrapped optimizer.
