I want `PointSource` to support a `"SOURCE_POSITION"` point-source model for lensed point sources whose parameters are given in the source plane. A user should be able to construct it as `PointSource(point_source_type_list=["SOURCE_POSITION"], lens_model=lens_model, fixed_magnification_list=[False], magnification_limit=None, kwargs_lens_eqn_solver=None, redshift_list=None)` and then call `source_position(kwargs_ps, kwargs_lens)`, `image_position(kwargs_ps, kwargs_lens)`, `image_amplitude(kwargs_ps, kwargs_lens)`, `source_amplitude(kwargs_ps, kwargs_lens)`, and `point_source_list(kwargs_ps, kwargs_lens)` on the same instance.

For a concrete session with `LensModel(lens_model_list=["SIS"])`, `kwargs_lens=[{"theta_E": 1, "center_x": 0, "center_y": 0}]`, and `kwargs_ps=[{"ra_source": 0.1, "dec_source": 0.0, "point_amp": [2, 1]}]`, `source_position` should return one source coordinate pair equal to `(0.1, 0.0)`. `image_position` should solve the lens equation for that source and return image-plane coordinate arrays whose ray-shooted positions map back to `(0.1, 0.0)`, approximately the two SIS images near `(1.1, 0.0)` and `(-0.9, 0.0)`. `image_amplitude` should return the explicit per-image `point_amp` values, expanded to the number of solved image positions when a scalar amplitude is provided, and `point_source_list` should flatten the solved image coordinates and amplitudes into `(ra_array, dec_array, amp_array)`.

When the same model is constructed with `fixed_magnification_list=[True]`, users should provide `source_amp` instead of `point_amp`; `image_amplitude` should multiply that source amplitude by the absolute lensing magnification at each solved image position, while `source_amplitude` should return the supplied intrinsic source amplitude. If the user supplies `mag_pert`, those fractional perturbations should multiply the returned image amplitudes and must be trimmed or validated against the number of image positions. Missing required source-plane coordinates such as `ra_source` or `dec_source` should raise `KeyError` from the call that needs them.
