I want the level editor's stateful `Editor` object to support redoing an undone edit with `Editor.redo(): void`. After an edit has been committed and `Editor.undo()` has been called, calling `Editor.redo()` should replay that same edit in forward order, move it back onto the undo history, update the modified/saved state consistently, refresh the editor buttons, and rehover the active mouse operation if one is running. Calling `Editor.redo()` when there is no redo history should be a no-op.

Users should also be able to invoke the same redo command from the editor UI: the menubar should include a `Redo` button, and the keyboard shortcuts Ctrl+Y and Ctrl+Shift+Z should call redo while the editor is active. If a user undoes an edit and then performs a new edit instead of redoing, the old redo history should be discarded so redo cannot replay a stale branch.
