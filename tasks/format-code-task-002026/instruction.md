I want the stateful iCn3D viewer API to support loading a membrane-oriented structure directly from an OPM PDB ID. In JavaScript, I should be able to construct `new iCn3DUI(cfg: object)` with `cfg.opmid = '6JXR'` and then call `await ui.show3DStructure(pdbStr?: string)` with no PDB text; the viewer should set the active input ID to `6JXR`, record the command text `load opm 6JXR`, fetch `https://opm-assets.storage.googleapis.com/pdb/6jxr.pdb`, and parse the returned PDB as OPM data so the viewer state has populated atoms, chains, residues, and `ui.icn3d.bOpm === true`.

For a direct OPM load, automatic rotation should be stopped, and the membrane plane controls should be initialized from the parsed half-bilayer size: `selectplane_z1` and `extra_mem_z` get the positive value, while `selectplane_z2` and `intra_mem_z` get the negative value. The command script interface should also accept `load opm 6JXR`, set the active OPM ID, and produce the same loaded state as the startup config path. If the OPM asset request fails because the ID is not available in OPM, the load should fail with the message `This is probably not a transmembrane protein. It has no data in Orientations of Proteins in Membranes(OPM) database.` and should not silently create an empty structure.
