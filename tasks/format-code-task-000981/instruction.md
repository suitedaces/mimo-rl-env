Vector rendering is intended to make dataview widgets work from the GeoJSON features already loaded in the browser, but the current providers are incomplete and their aggregate results diverge from the server-backed dataview responses at important boundaries. Finish the exported GeoJSON dataview providers so vector and remote layers expose the same observable data contract.

For a list dataview, getData must read the active feature set from the layer filter and return a server-shaped object with a rows array. Each row must contain exactly the requested columns, in the requested projection, preserving values such as 0, false, and null; a property that is absent from a feature is represented as null. Calls must return independent row objects and must not mutate the source feature properties.

Formula dataviews must calculate count, sum, avg, min, and max over the active features. Count includes every active feature, while nulls reports the number of null values in the selected column. Sum and average ignore nulls but include zero, and min/max must consider zero and negative values. If no non-null values exist, each numeric operation (sum, avg, min, max) returns null rather than NaN or an arbitrary sentinel. The existing error behavior for an unsupported operation remains intact.

Category dataviews use the unfiltered feature set when filterEnabled is false and the active filtered set when it is true. They report count, distinct categories, and nulls; categories are ordered by descending frequency, expose at most the five individual categories with the highest counts, and aggregate every remaining category into one {category: 'Other', agg: true} entry only in the unfiltered mode. Filtered mode must not emit an Other entry.

Histogram dataviews must honor explicit numeric start and end options, including zero, when determining bin_start and bin_width; they still report the requested bin count and the number of null values. All of these behaviors must remain available through the existing provider modules used by vector layers, without requiring a network request.
