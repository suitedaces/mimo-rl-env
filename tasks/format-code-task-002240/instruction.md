I want two one-shot C helper functions for quickly printing an fy_generic value to stdout: int fy_generic_emit_compact(fy_generic v) and int fy_generic_emit_default(fy_generic v). fy_generic_emit_compact(v) should serialize v as YAML in flow one-line style, strip document markers, write the serialized text to stdout, and return 0 on success. For example, calling fy_generic_emit_compact(fy_string("hello")) should print the YAML representation of that scalar to stdout and return 0, and calling it on fy_mapping("a", 1, "b", true) should print a one-line flow mapping such as {a: 1, b: true} followed by the normal emitter output behavior.

fy_generic_emit_default(v) should be the default quick-print helper for the same use case and should return the same result as compact emission for the same value. Both functions should use the existing generic encoder path so scalars, sequences, and mappings are emitted consistently with the rest of the generic API. If the emitter or encoder cannot be created, or if the value cannot be encoded, the function should return -1 rather than reporting success.
