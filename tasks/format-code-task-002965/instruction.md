I want a stateful `SixMonthCycle_Agent(window_size: int, small: int, large: int, signal: int, up: float, down: float)` strategy class that consumes prices and calendar dates one tick at a time. Its public `step(price, date: str) -> int` method should append the price to the agent's rolling memory and return one trading action per call: `1` for buy, `-1` for sell, and `0` for hold. Until the agent has received `window_size` prices, every `step` call should return `0` without trying to trade.

Once the memory window is full, the agent should parse dates in `YYYY-MM-DD` form, use the month field for the seasonal rule, and compute a MACD confirmation from the recent price window using the configured small EMA span, large EMA span, signal EMA span, and `up`/`down` thresholds. It should also provide `get_macd_signal() -> str`, returning `"buy"`, `"sell"`, or `"hold"` for the current memory window. The MACD result is `"buy"` when `macd >= (1 + up) * signal_line`, `"sell"` when `macd <= (1 - down) * signal_line`, and `"hold"` otherwise.

For a concrete session, `agent = SixMonthCycle_Agent(3, 1, 3, 2, 0, 0)` should return `[0, 0, 1]` for `step(10, "2020-09-01")`, `step(11, "2020-10-01")`, and `step(12, "2020-11-01")`; after those calls, `get_macd_signal()` should return `"buy"`. With a fresh `SixMonthCycle_Agent(3, 1, 3, 2, 0, 0)`, the calls `step(12, "2020-03-01")`, `step(11, "2020-04-01")`, and `step(10, "2020-05-01")` should return `[0, 0, -1]`, and `get_macd_signal()` should return `"sell"`. With rising prices `[10, 11, 12]` ending on `"2020-05-01"`, the third action should be `0` because May through October only sell when MACD confirms weakness.

The seasonal behavior should be: buy in November or December once the window is full, buy from January through April only when the MACD signal is `"buy"`, sell from May through October only when the MACD signal is `"sell"`, and otherwise hold. If the memory window is already full and `step` receives a date string whose year, month, or day parts cannot be parsed as integers, it should raise `ValueError`. Separate `SixMonthCycle_Agent` instances should keep independent price history and parameter settings.
