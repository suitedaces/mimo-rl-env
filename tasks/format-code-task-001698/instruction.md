Swap "Start story from here" with "Test from here" in passage bar
### Is your feature request related to a problem? Please describe.

When working on a project, testing from a specific passage is an extremely common action (for example in order to confirm how new changes look). Having to navigate to the top bar and click at least twice is a major downgrade compared to the seamless test from here in Twine 2.3

### Describe the solution you'd like.

The "Start story from here" option that is currently on quick shortcut in the passage bar can be swapped for "Test from here". It's not that often that an author changes the starting passage, compared to testing a passage.

### Describe alternatives you've considered.

An alternative solution would be to have both options in the passage bar.
