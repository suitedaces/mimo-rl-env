I want the Go SDK's chat bot upload APIs so a configured `Bot` can upload images and files to Feishu/Lark and return the platform keys needed for later messages.

In the root `lark` package, expose `func (bot Bot) UploadImage(string) (*UploadImageResponse, error)`, `func (bot Bot) UploadImageObject(image.Image) (*UploadImageResponse, error)`, and `func (bot Bot) UploadFile(UploadFileRequest) (*UploadFileResponse, error)`. In the `lark/v2` package, expose the context-aware forms `func (bot *Bot) UploadImage(context.Context, string) (*UploadImageResponse, error)`, `func (bot *Bot) UploadImageObject(context.Context, image.Image) (*UploadImageResponse, error)`, and `func (bot *Bot) UploadFile(context.Context, UploadFileRequest) (*UploadFileResponse, error)`.

`UploadImage` should open the supplied local path, build a multipart POST to `/open-apis/im/v1/images` with `image_type=message` and a file part named `image`, set the multipart `Content-Type`, use the SDK's authenticated request flow, decode the JSON response, and return an `UploadImageResponse` whose `Data.ImageKey` contains the returned `image_key`. `UploadImageObject` should accept an `image.Image`, encode it as JPEG into the multipart `image` part using a stable form filename such as `temp_image`, post to the same image endpoint, and return the same response type.

`UploadFileRequest` should provide `FileType string`, `FileName string`, `Duration int`, `Path string`, and `Reader io.Reader`. `UploadFile` should POST multipart data to `/open-apis/im/v1/files` with `file_type`, `file_name`, and a file part named `file`; when `Reader` is nil it should read bytes from `Path`, and when `Reader` is provided it should stream from that reader while using `FileName` as the form filename. For an mp4 upload with a positive `Duration`, include a `duration` form field formatted as decimal seconds; for other file types or non-positive durations, omit that field. It should decode the response into `UploadFileResponse` with `Data.FileKey` populated from `file_key`.

A concrete session should work like: create/configure a chat `Bot`, call `UploadImage("./fixtures/test.jpg")`, observe no Go error and a non-empty `resp.Data.ImageKey`; then call `UploadFile(UploadFileRequest{FileType: "pdf", FileName: "hello.pdf", Path: "./fixtures/test.pdf"})` and observe no Go error and a non-empty `resp.Data.FileKey`. Another session should call `UploadFile(UploadFileRequest{FileType: "stream", FileName: "test-data.csv", Reader: strings.NewReader("Name,Age\nFoo,25\n")})` and upload those reader bytes without needing a filesystem path.

If opening the local path fails, multipart file creation fails, copying or JPEG encoding fails, closing the multipart writer fails, the authenticated request fails, or response decoding fails, the method should return `nil` for the response and the encountered error. The v2 methods must honor the supplied `context.Context` through the request path, including cancellation or timeout errors from the HTTP layer.
