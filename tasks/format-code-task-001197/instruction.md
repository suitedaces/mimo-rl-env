I want the NES library to support iNES mapper 7 / AOROM cartridges when I create an emulator with `nes.NewConsole(path string) (*nes.Console, error)`. If the `.nes` header declares mapper ID 7 and the ROM data is otherwise valid, `NewConsole` should return a usable console instead of an unsupported-mapper error.

For mapper 7 cartridges, CPU reads from `$8000-$FFFF` should come from one 32 KB PRG-ROM bank, initially bank 0. CPU writes at `$8000-$FFFF` should select the active 32 KB PRG bank from the low three bits of the written value, so a later read from the same CPU address range reflects the selected bank. The same write should set single-screen nametable mirroring from bit 4: clear selects the first single-screen page and set selects the second single-screen page.

The mapper should make cartridge CHR memory available to the PPU at `$0000-$1FFF`, with PPU writes in that range updating CHR RAM when the cartridge uses writable CHR storage. CPU reads and writes at `$6000-$7FFF` should access cartridge SRAM at the matching offset. Console save/load state should preserve the mapper 7 selected PRG bank, so after loading a saved state, subsequent CPU reads continue from the same mapped bank.
