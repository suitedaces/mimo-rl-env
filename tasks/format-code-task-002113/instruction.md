I want the engine library to expose a `ConditionalMoveTree` class for building and transforming conditional Go move response trees in source code. The public constructor should be `new ConditionalMoveTree(move: string | null, parent?: ConditionalMoveTree)`, and instances should expose `move`, optional `parent`, and a `children` map keyed by encoded opponent moves.

`encode(): ConditionalMoveResponse` should recursively serialize a node as `[move, childMap]`; for example, if a root has `children["aa"] = new ConditionalMoveTree("bb", root)`, encoding the root should return `[null, {"aa": ["bb", {}]}]`. `ConditionalMoveTree.decode(data: ConditionalMoveResponse): ConditionalMoveTree` should rebuild that structure, including child `parent` links back to the decoded parent node. `getChild(mv: string): ConditionalMoveTree` should return the existing child for a known key, and for a missing key it should return a new node with `move === null` and `parent` set to the receiver without adding it to `children`.

`duplicate(): ConditionalMoveTree` should return a deep copy: mutating the copy's nested children must not mutate the original. `merge(other: ConditionalMoveTree): ConditionalMoveTree` should combine two trees into a new tree rooted at `move === null`; non-conflicting branches are kept, branches with the same opponent move and same planned response recursively merge their continuations, and branches with the same opponent move but different planned responses are replaced by the branch from `other`. `ConditionalMoveTree.fromMoveDiff(moves: string): ConditionalMoveTree` should build a tree from two-character encoded moves alternating opponent move then planned response; for `"aabb"` it should encode to `[null, {"aa": ["bb", {}]}]`, for `"aabbccdd"` it should encode to `[null, {"aa": ["bb", {"cc": ["dd", {}]}]}]`, and an odd-length move string such as `"abc"` should throw `Error("invalid move string")`.
