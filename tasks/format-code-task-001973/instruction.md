I want a `ReporterList(reporters: list)` class for training loops that keeps metric state across a sequence of calls. A typical session should look like `r = ReporterList(backends)`, then for each batch call `r.set_batch_size(batch_size)` and `r.add_value(key, value, is_averaged=True, reduction='average', no_sync=False)` or the aliases `r.add(...)` and `r(...)`, and at the end of the epoch call `r.report(step=None, mode='')`.

For scalar or tensor batch averages, `is_averaged=True` should weight each value by the current batch size before reducing, so adding loss values `[5, 20, 30, 1, 4, 8]` with batch sizes `[32, 32, 32, 32, 32, 10]` and then calling `report()` should put `(values * batches).sum() / batches.sum()` at `r.history['loss'][-1]`. With `reduction='sum'`, the epoch result should be the sum of the collected values, and with a callable reduction, the callable should receive the list of collected values and its return value should become the epoch result. If `value` is a dictionary, each dictionary key should be reduced across the epoch and reported as grouped scalars; if a tensor result has one element it should be sent as a scalar, and if it has multiple elements it should be sent as grouped scalars keyed by element index. Passing any reduction string other than `'sum'` or `'average'` should raise `ValueError`.

When `report(step, mode)` is called, stored keys should be written to history as `'<key>/<mode>'` when `mode` is non-empty, or just `'<key>'` otherwise, and each backend in `reporters` should receive `add_scalar`, `add_scalars`, and `flush` calls as appropriate. Calling `report()` again without new values should be a no-op so a single epoch is not reported twice. The `history` object should support both `r.history['loss']` and `r.history('loss')`, and `r.exit()` should clear the persistent history.

The same object should also forward non-epoch artifacts to compatible backends through `add_text(key, text, step=None)`, `add_figure(key, figure, step=None)`, `add_histogram(key, value, step=None, bins='tensorflow')`, and `add_image(key, image, step=None, normalize=False)`. If `normalize=True` for images, the image tensor should be min-max normalized before being forwarded. If no backend supports a requested artifact method, users should get a warning instead of a silent failure.
