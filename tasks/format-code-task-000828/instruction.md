I want react-image-crop to expose pure TypeScript helper functions for preparing an initial aspect-ratio crop before passing it to the React component.

`makeAspectCrop(crop: Pick<PercentCrop, 'unit'> & Partial<Omit<PercentCrop, 'unit'>>, aspect: number, containerWidth: number, containerHeight: number): PercentCrop` and `makeAspectCrop(crop: Pick<PixelCrop, 'unit'> & Partial<Omit<PixelCrop, 'unit'>>, aspect: number, containerWidth: number, containerHeight: number): PixelCrop` should take a partial crop and fill in the missing width or height so the result matches the requested aspect ratio while preserving the input unit. For example, `makeAspectCrop({ unit: '%', width: 50 }, 16 / 9, 400, 300)` should return `{ unit: '%', x: 0, y: 0, width: 50, height: 37.5 }`. If the requested aspect crop would overflow the container, it should shrink the overflowing dimension to fit; for example, `makeAspectCrop({ unit: 'px', x: 300, y: 0, width: 200 }, 1, 400, 300)` should return `{ unit: 'px', x: 300, y: 0, width: 100, height: 100 }`.

`centerCrop(crop: Pick<PercentCrop, 'unit'> & Partial<Omit<PercentCrop, 'unit'>>, containerWidth: number, containerHeight: number): PercentCrop` and `centerCrop(crop: Pick<PixelCrop, 'unit'> & Partial<Omit<PixelCrop, 'unit'>>, containerWidth: number, containerHeight: number): PixelCrop` should center a partial crop within the container and preserve the input unit. For example, `centerCrop({ unit: 'px', width: 100, height: 50 }, 400, 300)` should return `{ unit: 'px', x: 150, y: 125, width: 100, height: 50 }`, and `centerCrop({ unit: '%', width: 50, height: 25 }, 400, 200)` should return `{ unit: '%', x: 25, y: 37.5, width: 50, height: 25 }`.

Both helpers should be deterministic, should not mutate the crop object passed in, and should not perform filesystem, network, or global-state side effects.
