I want `asdf shimversions <command>` to show which installed plugin versions provide a shimmed command. When I install versions such as `dummy 3.0` and `dummy 1.0`, run `asdf reshim dummy`, and then run `asdf shimversions dummy`, stdout should contain one provider line per recorded version in the format `<plugin> <version>`, for example `dummy 3.0` and `dummy 1.0`, and the command should exit 0.

If I run `asdf shimversions` without a command name, it should print `usage: asdf shimversions <command>` to stderr and exit nonzero. If the asdf config cannot be loaded, it should report `error loading config: <error>` to stderr and fail nonzero. If the shim metadata for the requested command cannot be read, the command should fail nonzero without printing made-up provider lines.
