I want the filestack-js package to export server-side security helpers as pure functions from the top-level module: `getSecurity(policyOptions: SecurityOptions, appSecret: string): Security` and `validateWebhookSignature(secret: string, rawBody: string, toCompare: WebhookValidatePayload): boolean`. `SecurityOptions` should require `expiry: number` and allow only these optional keys: `call`, `handle`, `url`, `maxSize`, `minSize`, `path`, and `container`; `WebhookValidatePayload` should contain `timestamp: string` and `signature: string`.

In Node, `getSecurity` should validate the policy options, JSON-stringify the policy object as provided, base64-encode that JSON into `policy`, then compute `signature` as the lowercase hex HMAC-SHA256 of the base64 policy using `appSecret`. For `getSecurity({ expiry: 253381964415 }, "abc123")`, it should return `{ policy: "eyJleHBpcnkiOjI1MzM4MTk2NDQxNX0=", signature: "73f7e2f282432af9853e66237e78a6bbe3131091c0c8163c87a88a8e562818cd" }`. For `getSecurity({ expiry: 1523595600, handle: "TEST_HANDLE" }, "testAppSecret")`, it should return `{ policy: "eyJleHBpcnkiOjE1MjM1OTU2MDAsImhhbmRsZSI6IlRFU1RfSEFORExFIn0=", signature: "4c4103f55de507b5d51f595163c3f8759d04b663d0f5bb172b74c689804f35c8" }`. Invalid policy options such as `{ expiry: "test", handle: "TEST_HANDLE" }` should throw a `FilestackError` with the message `Invalid security params` and validation error details.

In Node, `validateWebhookSignature` should compute the lowercase hex HMAC-SHA256 of `${timestamp}.${rawBody}` using `secret` and return `true` only when it exactly equals `toCompare.signature`. For secret `abc123`, raw body `{"event":"test"}`, timestamp `42`, and signature `e9e2082b689b165cfcde5e0f3e3b146afece84e0c4d5e8b466d9b598e6a146d3`, it should return `true`; with the same inputs and a different signature, it should return `false`.

These helpers must be deterministic for the same inputs and must not mutate the provided policy or webhook payload objects. Browser builds should still expose the same function names, but calling `getSecurity` should throw `getSecurity is only supported in nodejs`, and calling `validateWebhookSignature` should throw `validateWebhookSignature is only supported in nodejs`.
