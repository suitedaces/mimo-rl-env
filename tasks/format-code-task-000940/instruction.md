I want Skunk to add derived metric methods to RubyCritic analysed file and collection objects so library and report code can ask those objects directly for SkunkScore data.

For a RubyCritic::AnalysedModule, provide public zero-argument methods skunk_score, penalty_factor, churn_times_cost, and to_hash. skunk_score should return the file cost rounded to 2 decimals when coverage is exactly 100; with cost 100 and coverage 100 it returns 100, with cost 100 and coverage 0 it returns 10000, and with cost 100 and coverage 75 it returns 2500. penalty_factor should be 100 minus integer coverage, so coverage 75 gives 25. churn_times_cost should multiply cost by churn and round to 2 decimals, treating zero or negative churn as 1; for cost 2.34 and churn 3 it returns 7.02, and for cost 2.34 and churn 0 it returns 2.34. to_hash should return a hash with file as the pathname string plus skunk_score, churn_times_cost, churn, cost rounded to 2 decimals, and coverage rounded to 2 decimals.

For a RubyCritic::AnalysedModulesCollection, provide public zero-argument methods analysed_modules_count, skunk_score_total, skunk_score_average, total_churn_times_cost, worst_module, sorted_modules, non_test_modules, files_as_hash, and to_hash. The collection metrics should ignore test files: paths under directories beginning or ending with test or spec, and filenames ending in _test.rb or _spec.rb, are excluded from counts, totals, rankings, and exported file lists. Given production modules lib/a.rb with skunk_score 10 and churn_times_cost 5, lib/b.rb with skunk_score 20 and churn_times_cost 7, and test/a_test.rb with skunk_score 999, analysed_modules_count returns 2, skunk_score_total returns 30, skunk_score_average returns 15.0, total_churn_times_cost returns 12, sorted_modules returns lib/b.rb before lib/a.rb, and worst_module returns lib/b.rb. For an empty collection, skunk_score_average returns 0.0 and worst_module returns nil. Collection to_hash should include analysed_modules_count, skunk_score_total, skunk_score_average, total_churn_times_cost, worst_pathname, worst_score, and files, where files is the sorted list of per-file hashes.
