I want a pure Go parsing function `syntax.Parse(s string) (*ast.Node, error)` that turns one glob pattern string into an AST without compiling or matching it. For `syntax.Parse("abc")`, it should return an `ast.Node` whose root has `KindPattern` and one `KindText` child with `ast.Text{Text: "abc"}`. For `syntax.Parse("a*c")`, it should return a `KindPattern` root with children `KindText("a")`, `KindAny`, and `KindText("c")`; for `syntax.Parse("a**c")` the middle child should be `KindSuper`, and for `syntax.Parse("a?c")` it should be `KindSingle`.

The parser should preserve character classes and ranges in the AST: `syntax.Parse("[az]")` should produce a `KindList` node with `ast.List{Chars: "az"}`, while `syntax.Parse("[!a-z]")` should produce a `KindRange` node with `ast.Range{Lo: 'a', Hi: 'z', Not: true}`. Alternatives should become `KindAnyOf` nodes containing `KindPattern` children, including nested alternatives and comma handling only inside braces; for example `syntax.Parse("/{z,ab}*")` should parse as text `/`, an alternatives node for `z` and `ab`, then `KindAny`. Backslash escapes should make glob operator characters literal, so escaped `*`, `?`, `[`, `{`, `}`, `\`, and comma text are emitted as text where appropriate.

Malformed patterns should return `nil` and a non-nil `error`, including unterminated ranges like `"[abc"`, impossible ranges like `"[z-a]"`, invalid UTF-8 input, and unexpected tokens. Calling `syntax.Parse` twice with the same string should return equal ASTs and should not mutate the input string or use filesystem, network, or hidden global state.
