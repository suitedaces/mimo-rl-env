I want the `sd/lb` package to provide retrying endpoint wrappers for load-balanced clients. The public API should include `func Retry(max int, timeout time.Duration, b Balancer) endpoint.Endpoint`, `type Callback func(n int, received error) (keepTrying bool, replacement error)`, and `func RetryWithCallback(timeout time.Duration, b Balancer, cb Callback) endpoint.Endpoint`.

When I create `retry := Retry(3, time.Second, balancer)` and call `retry(ctx, request)`, each failed attempt should ask `balancer.Endpoint()` for an endpoint, invoke that endpoint with the same request under the retry timeout, and continue until an endpoint returns a successful response, the attempt limit is reached, or the timeout expires. For example, with a round-robin balancer over endpoints that return `error one`, then `error two`, then `"ok"`, `Retry(3, time.Second, balancer)(ctx, req)` should return `"ok", nil`; with `Retry(2, time.Second, balancer)` over the same endpoints it should return an error after the second failed endpoint.

If the balancer has no endpoints, the returned endpoint should surface that failure through the retry path. If the timeout expires before an attempt returns, the returned endpoint should return the context deadline error. Passing a nil `Balancer` to `RetryWithCallback` should panic with `nil Balancer`.

`RetryWithCallback` should call the callback after each failed attempt with the 1-based attempt number and the exact error received from the balancer or endpoint. If the callback returns `false`, retries should stop immediately; if it also returns a replacement error, that replacement should become the final error. A nil callback should mean retry indefinitely until success or timeout.

Retry failures should be returned as a public `RetryError` value with `RawErrors []error`, `Final error`, and an `Error() string` method. The final error string should be the final error message, and when multiple failures occurred it should append the earlier errors in the form `final error (previously: first error; second error)`.
