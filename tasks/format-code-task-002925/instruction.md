I need `usbguard::Device` to expose `std::shared_ptr<usbguard::Rule> getDeviceRule(bool with_port = true, bool with_parent_hash = true, bool match_rule = false)` so code can turn an already-populated device object into the policy rule that matches that device.

For a device with rule ID 7, target `Rule::Target::Allow`, USB ID `1234:abcd`, serial `S123`, name `Example Keyboard`, connect type `hotplug`, port `1-2`, interface types `03:01:01` and `03:00:00`, finalized hash `deviceHash`, and explicit parent hash `parentHash`, `device.getDeviceRule(true, true, false)` should return a `Rule` whose serialized form contains those identity fields, includes `via-port "1-2"`, includes `with-connect-type "hotplug"`, includes `with-interface { 03:01:01 03:00:00 }`, includes `hash "deviceHash"`, includes `parent-hash "parentHash"`, and keeps the target as `allow`. With the same populated device, `device.getDeviceRule(false, false, true)` should return an equivalent matching rule that uses target `match`, omits the port attribute, and omits the parent-hash attribute while still carrying the USB ID, serial, name, connect type, interface types, and device hash.

If `with_parent_hash` is true and the device has no explicit parent hash, the method should use the parent device's hash from the owning `DeviceManager` when the parent ID refers to another device. If `with_parent_hash` is true, there is no explicit parent hash, and the device is attached to the root rather than another known device, the method should throw `std::runtime_error` instead of returning a partial rule.
