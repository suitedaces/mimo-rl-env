I want @react-facet/core to provide facet-aware React component helpers for mounting children from facet values.

The public exports should include `Mount`, `Map`, `With`, `Unwrap`, and `Times`. `Mount` should be usable as `<Mount when={facet}>{child}</Mount>` and render `child` only when the boolean facet value is `true`; when passed `condition={false}`, it should render only when the facet value is `false`. For example, with a facet initially set to `true`, `<Mount when={display}><div>Hello</div></Mount>` renders `Hello`, and with the same component driven by `false` it renders nothing.

`Unwrap` should be usable as `<Unwrap data={facet}>{value => node}</Unwrap>`. It should call the render prop with the current facet value once the facet has a concrete value, including `undefined` or `null`, and render nothing while the facet value is `NO_VALUE`. For example, a string facet set to `"Foo"` should render the result of `children("Foo")`, while a facet set to `NO_VALUE` should not call or display the child content.

`With` should be usable as `<With data={facet}>{nonNullFacet => node}</With>`. It should render only when the facet value is neither `null` nor `undefined`, and the render prop should receive a facet refined to the non-null value. For example, a facet holding `{ user: "Zelda" }` should let the child render `Zelda`, while a facet holding `null`, `undefined`, or `NO_VALUE` should render nothing; if the facet later changes to `null`, the child subtree should unmount.

`Map` should be usable as `<Map array={items}>{(itemFacet, index, length) => node}</Map>`. It should render one child per array item, pass each child a per-index facet for that item, pass the numeric index and total length, and update the mounted item count when the array facet grows or shrinks. For example, a facet holding five objects should render five children with indexes `0` through `4`, and after the array changes to two objects only two children should remain. When an `equalityCheck` is supplied, unchanged item facets should avoid notifying their child subtree while changed item positions still update.

`Times` should be usable as `<Times count={countFacet}>{(index, count) => node}</Times>`. It should render the child function exactly `count` times after the count facet has a concrete number, passing indexes from `0` through `count - 1` and the total count each time; for a count facet set to `3`, rendering the indexes should produce `012`.
