I want two one-shot conversion helpers in the yaml package: `func YAMLToJSON([]byte) ([]byte, error)` and `func JSONToYAML([]byte) ([]byte, error)`. `YAMLToJSON` should parse a YAML document, preserve map key order when possible, and return JSON bytes using the package's normal JSON-style formatting; for input `foo:\n  bar:\n  - a\n  - b\n  - c\na: 1\n` it should return `{"foo": {"bar": ["a", "b", "c"]}, "a": 1}\n` with a nil error. `JSONToYAML` should parse JSON bytes and return YAML bytes using the package's normal YAML formatting; for input `{"foo": {"bar": ["a", "b", "c"]}, "a": 1}` it should return `foo:\n  bar:\n  - a\n  - b\n  - c\na: 1\n` with a nil error. If the input cannot be parsed as the source format, the function should return a non-nil error and no successful output. Calling either function repeatedly with the same byte slice should produce the same result, should not mutate the input slice, and should not perform filesystem, network, or global-state side effects.
