Unify Samila's snapshot I/O so callers can move generated data and reproducible configs between files, memory, and path-like APIs without having to special-case each method.

The public `GenerativeImage(data=...)` and `GenerativeImage(config=...)` inputs must each accept a `collections.abc.Mapping`, a string path, any `os.PathLike`, or an already-open readable text or binary stream. Mapping support must not be limited to plain `dict`. Loading a data mapping must take a snapshot of its mutable content: later changes to the caller's point lists or nested plot values must not change the image, and changes to the image must not mutate the caller's mapping.

Likewise, `save_data` and `save_config` must each accept string paths, `os.PathLike` targets, and writable text or binary streams. Caller-owned streams are never closed by Samila, on either success or failure. Successful path saves keep the existing result shape with the absolute path in `message`; successful stream saves return `{"status": true, "message": "Everything seems good."}`. A stream write failure must continue to be reported as a false-status result whose message includes the underlying error, rather than being raised, and the stream must remain open.

Snapshots must round-trip all state relevant to reproducing the result. Data snapshots preserve both point arrays. Config snapshots preserve both function expressions plus `seed`, `start`, `step`, and `stop`, including explicit zero values. Both snapshot kinds preserve `color`, `bgcolor`, `spot_size`, `size`, `projection`, `alpha`, `linewidth`, and `depth`. JSON represents `size` as an array, but a loaded image exposes it in the library's tuple form.

Make load failures consistent at the package boundary. `samilaConfigError` must be importable from `samila`, alongside the existing data error. Malformed JSON, filesystem read failures, and a valid JSON document whose top level is not an object must raise `samilaDataError` for `data=` and `samilaConfigError` for `config=`; parser and I/O exceptions must be retained as the raised error's `__cause__`.

Keep legacy snapshots usable. A data object with no `plot` section uses the existing plot defaults. A config with no `generate` or `plot` section also uses existing defaults, and a config containing only `f1` or only `f2` still preserves that expression and generates the missing one as before.
