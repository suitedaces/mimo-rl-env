I want `XcodeProject` instances created with `XcodeProject(tree=None, path=None)` or `XcodeProject.load(path)` to provide search-path build-setting helpers that mutate the in-memory project before I call `save()`. The public methods should be `add_search_paths(path_type, paths, recursive=True, escape=False, target_name=None, configuration_name=None)`, `remove_search_paths(path_type, paths, target_name=None, configuration_name=None)`, `add_header_search_paths(paths, recursive=True, escape=False, target_name=None, configuration_name=None)`, `remove_header_search_paths(paths, target_name=None, configuration_name=None)`, `add_library_search_paths(paths, recursive=True, escape=False, target_name=None, configuration_name=None)`, `remove_library_search_paths(paths, target_name=None, configuration_name=None)`, `add_framework_search_paths(paths, recursive=True, escape=False, target_name=None, configuration_name=None)`, and `remove_framework_search_paths(paths, target_name=None, configuration_name=None)`.

For example, after `project.add_header_search_paths('path/to/search')`, every build configuration on every target should have `HEADER_SEARCH_PATHS` set to `path/to/search/**`. After `project.add_library_search_paths(['Libraries', 'Vendor Libs'], recursive=False, escape=True, target_name='app', configuration_name='Debug')`, only the `Debug` configuration for the `app` target should gain `LIBRARY_SEARCH_PATHS` values `"Libraries"` and `"Vendor Libs"`; other targets and configurations should not change. `add_framework_search_paths('Frameworks', recursive=True, escape=True)` should write `"Frameworks"/**`, while `add_framework_search_paths('$(inherited)', recursive=True, escape=True)` should write exactly `$(inherited)` with no quotes and no `/**` suffix. If a path already ends in `/**`, recursive addition should not append a second suffix. The remove methods should accept the same target and configuration filters and remove the requested literal search-path values from `HEADER_SEARCH_PATHS`, `LIBRARY_SEARCH_PATHS`, `FRAMEWORK_SEARCH_PATHS`, or an arbitrary search-path build setting passed to `remove_search_paths`.
