I want the Go compiler package to expose a one-shot function `CompileToInstructions(input string, pm parser.Mode) ([]*bytecode.InstructionSet, error)` for turning a Goby source string into VM instruction sets. Calling it should tokenize and parse the provided `input`, apply the supplied parser mode before parsing, initialize a fresh bytecode generator for that program, and return the generated instruction sets without retaining state between calls.

For `CompileToInstructions("1 + 2", parser.NormalMode)`, it should return no error and one `ProgramStart` instruction set whose first instructions include `putobject` for `1`, `putobject` for `2`, `send` for `+`, followed by `pop` and `leave` on source line 1. For `CompileToInstructions("module Foo\nend\n", parser.TestMode)`, it should return no error and instruction sets for the `Foo` module/class body plus the top-level `ProgramStart` body. For malformed input such as `CompileToInstructions("iff\nend\n", parser.REPLMode)`, it should return a non-nil error with the parser message, for example `unexpected end Line: 1`, and no instruction sets. Repeated calls with the same source and mode should produce equivalent instruction data and should not mutate the input string or depend on hidden global compiler state.
