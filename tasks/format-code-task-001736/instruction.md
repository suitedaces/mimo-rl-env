I want `clientcmd.ParseTimeout(duration string) (time.Duration, error)` so callers can parse Kubernetes request timeout strings before putting them into a REST client config. A bare non-negative integer should be interpreted as seconds: `ParseTimeout("0")` returns `0` with no error, and `ParseTimeout("15")` returns `15 * time.Second` with no error. Duration strings accepted by Go duration parsing should also work, so `ParseTimeout("2m")` returns `2 * time.Minute` and `ParseTimeout("1500ms")` returns `1500 * time.Millisecond` with no error.

For invalid input such as `ParseTimeout("abc")`, the function should return a zero duration and a non-nil error whose message contains `Invalid timeout value`. Calling it repeatedly with the same input should return the same result, and it should not read or write files, use the network, or mutate global state.
