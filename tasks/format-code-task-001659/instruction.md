I want `pdfplumber.utils.dedupe_chars(chars, tolerance=1, extra_attrs=("fontname", "size")) -> list[dict]` to return a new list with duplicate PDF character dictionaries removed. Two characters count as duplicates when they have the same `upright` and `text` values, the same values for every name in `extra_attrs`, and their `doctop` and `x0` positions fall within the numeric `tolerance`; from each duplicate cluster, keep the character with the smallest `(doctop, x0)` and return kept characters in their original input order.

For example, with `extra_attrs=("fontname", "size")`, two adjacent `{"text": "A", "upright": True, "fontname": "F1", "size": 12, "doctop": 10, "x0": 20}`-style chars whose second copy is at `doctop=10.4` and `x0=20.5` should collapse to one char at the default tolerance. Passing a lower tolerance such as `tolerance=0.1` should keep chars whose positions differ by more than that value. Calling the function twice with equal inputs should produce equal outputs, and it must not mutate the input list or any character dictionaries. If a character is missing a required field such as `text`, `upright`, `doctop`, `x0`, or a requested `extra_attrs` key, the function should raise `KeyError`.
