The `metric`, `cutoff`, `n_jobs`, and extra keyword arguments should be passed through to the selected distance calculator, so callers can use built-in metrics or a custom `DistanceCalculator`. A non-string sequence item such as `None` should raise `AttributeError` when it cannot be uppercased rather than being silently coerced. Repeating the same call should return an equal matrix, with no filesystem writes, network calls, or hidden global-state changes. I also want `scirpy.ir_dist.tcr_dist(*args, **kwargs)` as a compatibility alias that returns exactly what `sequence_dist(*args, **kwargs)` returns.
