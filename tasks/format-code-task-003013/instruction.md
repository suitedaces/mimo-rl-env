I want a default-exported project template manager object for workflow templates. It should expose `getTemplateDir(projectPath = window.currentProject?.path)`, `getTemplateListByProject(projectPath)`, `getTemplateList()`, `saveTemplate(name, templateData)`, `loadTemplate(fileName, projectPath = window.currentProject?.path)`, and `deleteTemplate(fileName)`.

`getTemplateDir` should require an open project path, throw `Error('没有打开的项目')` when none is available, create a `templates` directory under the project if it does not exist, and return that directory path. `getTemplateListByProject('/proj')` should read only `.json` files from `/proj/templates` and return summary objects with `name`, `description`, `version`, `created`, `fileName`, and `nodeCount` from each template file; for example, a file `drive.json` containing two nodes should appear as `{ name: 'Drive', description: '...', version: '1.0.0', created: '2026-01-01T00:00:00.000Z', fileName: 'drive.json', nodeCount: 2 }`. If listing or parsing fails, it should log the failure and return an empty array.

`saveTemplate('drive', data)` should write pretty-printed JSON to the current project template directory as `drive.json` and resolve to `'drive.json'`; on failure it should log and rethrow the error. `loadTemplate('drive.json', projectPath)` should read and parse the template, drop any nodes that do not have a `path`, and give any node with a missing or non-numeric `position.x` or `position.y` a default position of `{ x: 100, y: 100 }` before returning the template data. `deleteTemplate('drive.json')` should remove that file from the current project template directory and resolve to `true`, while logging and rethrowing failures.
