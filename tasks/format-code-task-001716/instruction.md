Standardize the asynchronous cacheResults helper used by the task-executor and worker services. These packages carry two copies of the helper and they currently disagree during a refresh: one returns a null placeholder to a concurrent caller while the other starts a second upstream request. Both behaviors are unsafe for the discovery/configuration reads that use this helper. Bring the two public helpers to one small, predictable contract.

The returned wrapper remains asynchronous and represents one cache for that wrapper, rather than a cache keyed by arguments. On a miss it invokes the supplied function with the receiver and arguments from the call that starts the refresh, and caches the exact resolved value. A settled value is reused while its age is strictly less than the supplied TTL; age is measured from settlement, so the boundary at exactly TTL is expired. A non-positive TTL never reuses a settled value on a later call, although concurrent callers of the same pending refresh still coalesce.

If a call arrives while a miss or expired refresh is pending, it must await that same generation: invoke the function once, expose its resolved value to every waiter, and never hand a waiter the previous stale value. Both promise rejections and synchronous throws are delivered to all waiters and must discard that generation so a later call retries the function. Legitimate results include null, false, zero, and undefined and must remain cacheable.

Preserve the existing _clearCache hook. Clearing removes the settled value immediately; if a refresh is in flight, callers already waiting for that generation may finish normally, but a subsequent call must start a new generation and the old generation must not repopulate the cache after it settles. Calls made while a valid entry exists continue to receive that entry even if they pass different arguments or a different receiver; arguments and receiver matter again only when a new refresh begins. Apply these semantics identically to both service copies so their callers can rely on the same behavior.
