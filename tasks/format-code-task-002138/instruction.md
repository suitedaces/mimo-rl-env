## Word Cloud components don't show up in course content search

I'm building a course with a number of Word Cloud components scattered across different sections. Each has a meaningful display name and a paragraph of instructions explaining what the learners are supposed to brainstorm (e.g. display name "Climate Brainstorm", instructions describing the prompt).

When I later try to jump back to one of them from Studio's content search by typing words from its display name or from its instructions text, no result comes back. The same kind of search works fine for HTML components, videos, problems, etc. — they get matched on their visible text — but Word Clouds simply never appear in the results, regardless of what I type.

Since the display name and the instructions are author-authored text and they're the natural things a course team would search for to locate a particular Word Cloud, it'd be great if Word Cloud components were searchable like the rest of the components. Right now they're effectively invisible to the search index.
