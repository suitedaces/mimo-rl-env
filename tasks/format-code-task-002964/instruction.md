I want a stateful `Momentum_Agent` class for moving-momentum trading signals. Users should construct it as `Momentum_Agent(window_size, small_sma=20, large_sma=150, stoch_osc_days=14, stoch_osc_oversold=20, stoch_osc_overbought=80, small_ema=12, large_ema=26, signal_ema=9)` and then call `step(price) -> int` once per closing price.

The agent should keep the latest `window_size` prices in instance state. `step(price)` should append the new price and return `0` until enough prices have been accumulated. Once the window is full, it should compute the short SMA minus long SMA trading bias, the stochastic oscillator over the configured day window, and a MACD-style histogram from exponential moving averages; it should return `1` for buy when the bias is positive, the stochastic oscillator is below 20, and the histogram is positive; return `-1` for sell when the bias is negative, the stochastic oscillator is above 80, and the histogram is negative; otherwise return `0` for hold.

For a compact test session, `agent = Momentum_Agent(5, 2, 5, 5, 20, 80, 2, 5, 3)` should return `[0, 0, 0, 0, 1]` when fed prices `[7, 1, 1, 5, 2]` through consecutive `step` calls. A separate `Momentum_Agent(5, 2, 5, 5, 20, 80, 2, 5, 3)` should return `[0, 0, 0, 0, -1]` for prices `[1, 6, 7, 3, 6]`. The class should also expose `get_sma(window)`, `get_stoch_osc(days)`, and `get_macd_hist(small, large, signal, price)` so callers can inspect the current window's indicator values after feeding prices, and separate agent instances should not share price memory.
