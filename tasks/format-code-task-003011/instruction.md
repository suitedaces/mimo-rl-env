I want wx.lib.pubsub's stateful publisher API to support removing listeners from topics after they have been subscribed. The default pub module should expose unsubscribe(listener, topicName) and unsubAll(topicName=None, listenerFilter=None, topicFilter=None), and Publisher instances should provide the same methods.

In a session like `from wx.lib.pubsub import pub`, after I subscribe two listener callables to `orders.created`, calling `pub.unsubscribe(first_listener, 'orders.created')` should return the pubsub Listener wrapper for that callable, remove only that listener from the topic, and make later `pub.sendMessage('orders.created', ...)` calls skip it while still delivering to the second listener. Calling `pub.unsubscribe(first_listener, 'orders.created')` again should return None and leave the existing subscriptions unchanged. Calling `pub.unsubscribe(listener, 'missing.topic')` for a topic that does not exist should raise TopicNameError.

I also need bulk removal. `pub.unsubAll('orders.created')` should remove every listener subscribed directly to that topic and return the list of removed Listener wrappers. `pub.unsubAll('orders.created', listenerFilter=pred)` should call the predicate with each Listener wrapper and remove only wrappers for which it returns True. `pub.unsubAll(listenerFilter=pred)` should apply that filter across all existing topics, and `pub.unsubAll(topicFilter=pred)` should limit bulk removal to topic names accepted by the topic predicate. `pub.unsubAll()` with no arguments should remove listeners from all topics and return all removed Listener wrappers.

Whenever a listener is actually removed, registered notification handlers with unsubscribe notifications enabled should receive one unsubscribe notification for that listener and topic. No unsubscribe notification should be emitted when the requested listener was not subscribed.
