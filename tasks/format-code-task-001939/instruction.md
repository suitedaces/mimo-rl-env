If the same body is compiled without `<mj-preview>`, or with an empty `<mj-preview></mj-preview>`, the returned `html` should not contain an empty preview container or the hidden preview styles. In strict validation mode, `<mj-preview>` should be accepted as a child of `<mj-head>` and should behave as an ending tag whose text content is used as the preview string. Calling `mjml2html` repeatedly with the same MJML and options should produce equivalent preview output each time.
