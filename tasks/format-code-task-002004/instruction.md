I want the indexer token-selection helpers to expose pure functions for turning document fields into the terms that get stored in the tiny search index. The main entry point should be `tokenize_document(url: str, title_cleaned: str, extract: str, score) -> TokenizedDocument`, and it should return a `TokenizedDocument` with the original `url`, `title`, `extract`, and `score` values plus a token list built from the title, prepared URL, and extract.

`prepare_url_for_tokenizing(url: str) -> str` should strip a leading `http://` or `https://` and replace `/`, `.`, and `_` with spaces. For example, `prepare_url_for_tokenizing("https://Example.com/docs/page_one.html")` should return `"Example com docs page one html"`, and `prepare_url_for_tokenizing("http://example.com/a_b.c/d")` should return `"example com a b c d"`.

`get_index_tokens(tokens: list[str]) -> set[str]` should include the first 10 tokens and up to the first 10 adjacent bigrams. For `['one', 'two', 'three', 'four']`, it should return `{'one', 'two', 'three', 'four', 'one two', 'two three', 'three four'}`. For `[str(i) for i in range(12)]`, it should include unigrams `'0'` through `'9'`, exclude unigram `'10'`, and include bigrams `'0 1'` through `'9 10'`.

For `tokenize_document("https://Example.com/docs/page_one.html", "Rust Async Runtime", "fast async runtime primitives", 0.75)`, the returned token set should be `{'rust', 'async', 'runtime', 'rust async', 'async runtime', 'example', 'com', 'docs', 'page', 'one', 'html', 'example com', 'com docs', 'docs page', 'page one', 'one html', 'fast', 'primitives', 'fast async', 'runtime primitives'}` and the returned score should be `0.75`. Calling the same function with `("http://example.com/a_b.c/d", "A B C D E F G H I J K L", "one two three four five six seven eight nine ten eleven", None)` should preserve `score is None`, lowercase all text tokens, include only the first 10 title unigrams plus the first 10 title bigrams, and include extract bigrams through `'ten eleven'`.

Invalid non-string inputs should fail normally instead of being coerced; for example `tokenize_document(None, "Title", "extract", 0)` should raise `TypeError`. These helpers should be referentially transparent: repeated calls with the same inputs should produce equal field values and equal token sets, should not mutate the input token list passed to `get_index_tokens`, and should not read or write files, perform network access, or update hidden global state.
