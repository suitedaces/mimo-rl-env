I want libcache to provide a least-frequently-used cache replacement policy for stateful cache instances. In Go, I should be able to import `github.com/shaj13/libcache/lfu` and call `lfu.New(cap int) libcache.Cache`; if I blank-import that package, `libcache.LFU.Available()` should be true and `libcache.LFU.New(cap int)` / `libcache.LFU.NewUnsafe(cap int)` should construct LFU-backed caches.

A cache created with capacity 3 should evict the key with the lowest successful `Load` count when adding a fourth entry. For example: `c := lfu.New(3)`, then `Store("a", 1)`, `Store("b", 2)`, `Store("c", 3)`, `Load("a")` twice, `Load("b")` once, and `Store("d", 4)` should leave `"a"`, `"b"`, and `"d"` present while `Load("c")` returns `(nil, false)`. `Peek`, `Contains`, and `Update` should not increase an entry's frequency, so checking or updating a low-frequency key should not protect it from the next LFU eviction.

The same victim selection should apply when `Resize` makes the cache smaller: after distinct access counts are established, reducing capacity should discard the least-loaded entries first and return the number evicted. If a remove notification channel is registered, overflow and resize evictions should report the actual LFU victim key and value. Separate LFU cache instances must maintain independent frequency counts and eviction order.
