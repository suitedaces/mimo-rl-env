Kedro plugins consume Pipeline.to_json() as a machine-readable description, but the current output is lossy and unstable: it flattens mapping declarations, omits node metadata, and exposes set iteration order. Upgrade this public serializer into a canonical pipeline manifest without breaking the existing top-level shape. The returned string must be valid JSON with the current Kedro version and a pipeline array in the pipeline's execution order. Each node entry must retain the node's public name (including namespace), and preserve the original input and output declaration form: None stays null, a scalar stays a string, lists stay lists, and argument/output mappings stay JSON objects with their aliases. Include tags, confirmations, and namespace for every node; represent absent tags or confirmations as empty arrays and an absent namespace as null. Tags and confirmations must be sorted so their order is deterministic, and equivalent pipelines built with nodes supplied in different insertion orders must serialize to identical strings. Keep the existing behavior for ordinary un-namespaced nodes and do not include private implementation details or callable bodies in the manifest.
