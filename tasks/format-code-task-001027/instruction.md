Optic JSON persistence is intended to be a stable interchange boundary, but several ordinary systems cannot currently make a save/load round trip. An optic with no aperture crashes during loading, the optic name is silently discarded, and enabling polarization leaves a `PolarizationState` object in the dictionary so `save_optiland_file` cannot emit JSON. Solved systems can also leak one-element NumPy arrays into coordinate serialization. At the same time, files written by older Optiland versions put polarization inside the wavelength section, so a format cleanup must not strand existing files.

Make `Optic.to_dict()` and `Optic.from_dict()`, and therefore `save_optiland_file()`/`load_optiland_file()`, a complete and backward-compatible persistence boundary. New dictionaries must carry the optional optic `name` (including `null`) and a top-level `polarization` value. The value is the literal string `"ignore"`, or an object with exactly `is_polarized`, `Ex`, `Ey`, `phase_x`, and `phase_y` fields for a `PolarizationState`; all of those values must be JSON-native and restore to an equivalent `PolarizationState`. New output must not put polarization under `wavelengths`.

Loading must accept `aperture: null`, absent `name` or `version`, and a missing `fields.object_space_telecentric` flag, using `None`/`False` defaults. For compatibility, when top-level `polarization` is absent, read the old `wavelengths.polarization` representation (including a serialized state object); if both locations exist, the top-level value wins. Existing field coordinates and vignetting, wavelength units and converted values, primary-wavelength selection, field type, and telecentric state must survive a round trip.

Pickup and solve declarations must remain registered after loading. Restoring them must not corrupt the already serialized geometry: a loaded pickup must still recalculate its target when `update()` is called, and a solved optic must be serializable with numeric coordinate values and the same public surface positions after loading. Preserve the existing JSON wrapper entry points and ordinary optics with an aperture while making these edge cases work.
