I want the `python -m peachpy.x86_64` compiler command to support Makefile dependency generation with `-MMD` and `-MF`. When I run `python -m peachpy.x86_64 -MMD -MF build/kernel.d -mabi=sysv -mimage-format=elf -o build/kernel.o src/kernel.py` and the PeachPy source compiles successfully, the command should still write `build/kernel.o` normally and should also write `build/kernel.d`.

The dependency file should contain a single Makefile rule whose target is the output path, followed by backslash-continued dependencies. The first dependency must be the input script path exactly as passed on the command line, and the remaining dependencies must be the sorted Python source files for modules loaded from the input script directory and any directories passed with `-I`. Modules outside those monitored directories should be ignored, duplicate module files should appear only once, and loaded `.pyc` or `.pyo` files should be reported as their matching `.py` source file when that source exists.

If `-MMD` is present without `-MF`, the dependency file should default to the output path plus `.d`, such as `build/kernel.o.d`. `python -m peachpy.x86_64 --help` should list `-MMD` as generating a Makefile describing dependencies and `-MF` as selecting the dependency output path.
