I want an `AlignedDataset` class for paired image-to-image training data, selectable as dataset mode `aligned` through the existing data-loader API. It should be used as a stateful dataset object: `ds = AlignedDataset(); parser = AlignedDataset.modify_commandline_options(parser, is_train); ds.initialize(opt); n = len(ds); sample = ds[index]; ds.name()`. The option hook should return the parser unchanged. `initialize(opt)` should read paired samples from `<opt.dataroot>/<opt.phase>`, sort the discovered file paths, store the options on the instance, and require `opt.resize_or_crop == 'resize_and_crop'` by raising an assertion failure otherwise. After initialization, `len(ds)` should equal the number of discovered paired files, and separate instances initialized with different options should keep their own roots and path lists. For `ds[index]`, each paired file is one RGB image with domain A on the left half and domain B on the right half; the method should split the image at half width, resize each half to `opt.loadSize x opt.loadSize`, convert both halves to tensors, and crop both tensors with the same `opt.fineSize` window. When `opt.no_flip` is true, the crop window should be the centered deterministic offset; otherwise the crop offsets should be random, and a later random horizontal flip should flip A and B together. Both tensors should be normalized with mean/std `(0.5, 0.5, 0.5)`. Channel handling should respect `opt.which_direction`: for `BtoA`, effective input channels come from `opt.output_nc` and output channels from `opt.input_nc`; otherwise they come from `opt.input_nc` and `opt.output_nc`. If the effective input or output channel count is 1, convert the corresponding normalized RGB tensor to a single grayscale channel using weights `0.299`, `0.587`, and `0.114`. Each sample should return exactly `{'A': A, 'B': B, 'A_paths': path, 'B_paths': path}`, with both path fields pointing to the paired source image, and `name()` should return `AlignedDataset`.
