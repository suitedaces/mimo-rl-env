I want @microlink/mql to expose pure query-building helpers for Microlink API requests. The CommonJS default export should have mql.getApiUrl and mql.mapRules, and the ESM entry should also provide named exports getApiUrl and mapRules.

mql.getApiUrl(url: string, opts?: object, gotOpts?: object) should return [apiUrl: string, fetchOptions: object] without performing a network request. For mql.getApiUrl('https://kikobeats.com') it should return ['https://api.microlink.io/?url=https%3A%2F%2Fkikobeats.com', { responseType: 'json', headers: {} }]. For mql.getApiUrl('https://kikobeats.com', { apiKey: 'foobar' }) it should use the pro endpoint and return ['https://pro.microlink.io/?url=https%3A%2F%2Fkikobeats.com', { responseType: 'json', headers: { 'x-api-key': 'foobar' } }]. If opts.endpoint is provided it should be used instead of the default free or pro endpoint, and if gotOpts contains headers or other fetch settings they should be carried into the returned fetchOptions. Nested option objects should be flattened into dotted query parameters, so { overlay: { browser: 'dark' } } produces an overlay.browser=dark query parameter. When opts.stream is truthy, the returned fetchOptions.responseType should be 'arrayBuffer'.

mql.mapRules(rules?: object) should flatten custom data extraction rules into Microlink data.* query keys and stringify their leaf values. For a rule with avatar.type = 'image' and avatar.selectors.selector = '#avatar', it should return { 'data.avatar.selectors.selector': '#avatar', 'data.avatar.type': 'image' }. For no rules, false, or a string, it should return undefined; for an empty object or array, it should return an empty object. Calling these helpers with the same inputs should produce equal outputs, should not mutate the input objects, and should not touch the filesystem, network, or global state.
