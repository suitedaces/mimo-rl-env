I want the `fabulous.text` module to provide a terminal-renderable `Text` class for large TrueType text. The constructor should be `Text(text, fsize=23, color="#0099ff", shadow=False, skew=None, font="NotoSans-Bold")`, where `text` is a string, `fsize` is the point size, `color` accepts HTML/CSS color names or hex values, `shadow=True` adds a gray translucent drop shadow, `skew` applies the slanted logo-style transform, and `font` accepts either a discoverable font name without extension or an absolute font file path.

A `Text("Fabulous", shadow=True, skew=5)` object should behave like the other Fabulous image renderables: converting it with `str()` or iterating it should produce non-empty terminal-printable ANSI color rows. `Text("lorem ipsum", font="NotoSans-Bold")` should render successfully using the bundled NotoSans font, and Unicode input such as `Text(u"😃", font="NotoEmoji-Regular")` should render without corrupting the input string.

I also need font discovery helpers in the same module. `get_font_files()` should return a dictionary mapping font names such as `NotoSans-Bold` to absolute `.ttf` or `.otf` paths, including bundled fonts and fonts under common system and user font directories. `resolve_font("NotoSans-Bold")` should return the absolute bundled `NotoSans-Bold.ttf` path, `resolve_font(<absolute existing font path>)` should return that absolute path unchanged, and an unknown font name should raise `FontNotFound`, a `ValueError` subclass.
