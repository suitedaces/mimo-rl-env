I want `Compile(pattern string, separators ...rune) (Glob, error)` to support brace alternatives in glob patterns, with the returned `Glob.Match(s string) bool` matching the whole input when any alternative branch matches. For `g, err := glob.Compile("{cat,dog}")`, `err` should be nil, `g.Match("cat")` and `g.Match("dog")` should return true, and `g.Match("cow")` should return false. For `g, err := glob.Compile("file{,.bak}")`, `err` should be nil, `g.Match("file")` and `g.Match("file.bak")` should return true, while `g.Match("file.tmp")` should return false.

Alternatives should compose with the rest of the pattern instead of only working as the entire pattern: `glob.Compile("{api,web}.example.com")` should match `api.example.com` and `web.example.com` but not `db.example.com`. Repeated calls to `Match` on the same compiled glob with the same input should return the same boolean result and should not mutate the compiled glob or the input string.
