I want a pure library function `bbox.utils.nms(bbl, scores, thresh)` for non-maximum suppression over 2D detections. `bbl` should be a `BBox2DList`, `scores` should be a Python list or numpy array with one confidence score per box, and `thresh` should be the IoU threshold; the function should return a numpy integer array containing the original indices of the boxes kept after suppression.

For `BBox2DList([[0, 0, 10, 10], [0, 0, 10, 10], [20, 20, 5, 5]])`, `scores=[0.2, 0.9, 0.5]`, and `thresh=0.5`, it should return `np.array([1, 2], dtype=int)` because the highest-scoring duplicate is kept and the lower-scoring duplicate is suppressed. For `BBox2DList([[0, 0, 10, 10], [5, 5, 10, 10]])`, `scores=np.array([0.6, 0.7])`, and `thresh=0.2`, it should return `np.array([1, 0], dtype=int)` in descending score order because their overlap is below the threshold. For an empty `BBox2DList([])`, it should return an empty numpy integer array.

If `scores` is not a list or numpy array, `nms` should raise `ValueError`. If the number of scores does not match the number of boxes, it should raise `ValueError`. Calling `nms` repeatedly with the same inputs should produce the same result, and the function should not mutate the input box list or score object or perform filesystem, network, or global-state side effects.
