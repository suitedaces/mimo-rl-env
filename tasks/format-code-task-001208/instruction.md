I want `LogicAnalyzer` to expose `get_xy(timestamps: list[numpy.ndarray], initial_states: dict[str, bool] | None = None) -> list[numpy.ndarray]` so captured digital event timestamps can be plotted as step waveforms. After a one-channel capture on LA1 in `any` mode, `get_xy([np.array([2.0, 5.0])], {"LA1": False})` should return `[np.array([0, 2.0, 2.0, 2.0, 5.0, 5.0, 5.0]), np.array([False, False, True, True, True, False, False])]`. After a one-channel capture on LA1 in `rising` mode, `get_xy([np.array([3.0, 7.0])], {"LA1": True})` should return an x array `[0, 3.0, 3.0, 3.0, 7.0, 7.0, 7.0]` and a y array `[False, False, True, False, False, True, False]`. After a one-channel capture on LA1 in `falling` mode with timestamps `[4.0]`, the y array should show a falling pulse shape `[True, True, False, True]` at x values `[0, 4.0, 4.0, 4.0]`. For multiple captured channels, the result should be a flat list ordered as `[x1, y1, x2, y2, ...]`, matching the active logic analyzer channel order. If `initial_states` is omitted, `get_xy` should read the current capture's initial digital states itself before building the arrays.
