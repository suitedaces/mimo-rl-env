I want a `SceneLoader` library class for loading NAVSIM/OpenScene log pickle data into scene objects. The public constructor should be `SceneLoader(data_path: pathlib.Path, sensor_blobs_path: pathlib.Path, scene_filter: SceneFilter, sensor_config: SensorConfig = SensorConfig.build_no_sensors())`; constructing it should scan the pickle files in `data_path`, apply the supplied `SceneFilter`, and retain the accepted frame windows for later lookup.

The loader should expose `tokens: list[str]`, `num_future_frames: int`, `num_history_frames: int`, `__len__() -> int`, `__getitem__(idx) -> str`, `get_scene_from_token(token: str) -> Scene`, `get_agent_input_from_token(token: str) -> AgentInput`, and `get_tokens_list_per_log() -> dict[str, list[str]]`. If `data_path` contains `log_a.pkl` with frames whose current-frame tokens are `a0`, `a1`, and `a2`, then a filter with `tokens=["a1", "a2"]` should make `loader.tokens == ["a1", "a2"]`, `len(loader) == 2`, `loader[0] == "a1"`, and `loader[1] == "a2"`. If `scene_filter.log_names == ["log_a"]`, only `log_a.pkl` should be considered; if `scene_filter.max_scenes == 1`, loading should stop after the first accepted scene.

Scene filtering should split each log's frame list into windows of `scene_filter.num_frames` using `scene_filter.frame_interval`, skip windows shorter than `scene_filter.num_frames`, skip windows whose current frame has no `roadblock_ids` when `scene_filter.has_route` is true, and use the token from `num_history_frames - 1` as the scene token. `get_scene_from_token("a1")` should return a full `Scene` built from the stored frame window with the configured history length, future length, sensor blob path, and sensor config. `get_agent_input_from_token("a1")` should return the history-only `AgentInput` for the same token and sensor config. Calling either lookup with a token that is not in `loader.tokens` should raise `AssertionError`. `get_tokens_list_per_log()` should group the accepted tokens by each frame window's `log_name`, preserving the accepted token order per log.
