I want the Vue 2 <virtual-list> component to expose scroll-position events while it manages its virtual range. When a user scrolls the list and the scroll position is valid, the component should emit a scroll event with the original browser scroll event and the current rendered range object. The range payload should reflect the updated virtual window, including start, end, padFront, and padBehind.

I also need top and bottom edge notifications for infinite loading. The component should accept top-threshold and bottom-threshold numeric props, both defaulting to 0. When the list is non-empty and the user scrolls toward the front so that the current offset is within top-threshold of the start, it should emit totop with no payload. When the user scrolls toward the end so that offset + viewport size + bottom-threshold reaches or passes the full scroll size, it should emit tobottom with no payload. These edge events should be based on scroll direction so scrolling away from an edge does not fire the opposite edge notification.
