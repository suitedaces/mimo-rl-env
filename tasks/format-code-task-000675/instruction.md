I want ckb-daemon's command FIFO to support a shorthand live RGB command where a bare six-digit hex color after `rgb` applies to every LED in the currently selected mode. For example, after a device is active, writing `rgb ff0000` should make every key or lighting zone red, and writing `rgb 000000` should turn every key or lighting zone off. The shorthand should behave like applying that same color across the whole device, so users do not have to enumerate individual keys or use a longer all-LED selector just to set a single solid color.
