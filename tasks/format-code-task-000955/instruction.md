The same import path should also recognize folded flamegraph text when it is supplied as bytes, including `ArrayBuffer`, `Uint8Array`, or `Buffer`, by sniffing the first line before falling back to JSON parsing. Malformed non-empty folded-flamegraph lines should not abort the whole import; they should be skipped so valid lines in the same input still produce samples. Inputs that are JSON objects or JSON strings, including text beginning with `{`, must not be misdetected as folded flamegraph text and should continue through the existing JSON/profile import path. Calling `unserializeProfileOfArbitraryFormat` multiple times with the same folded flamegraph text should produce equivalent processed profiles without mutating the input string or relying on hidden global state.
