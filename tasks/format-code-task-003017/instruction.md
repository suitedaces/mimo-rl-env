I want a pure `space_timesteps(num_timesteps: int, section_counts: Union[str, Sequence[int]]) -> set[int]` function for choosing which original diffusion timesteps to keep when building a shorter sampling or training schedule. If `section_counts` is a sequence of integers, the function should split the original timeline into equally sized sections, distribute any remainder one step at a time to the earliest sections, and choose each section's requested number of rounded, evenly spaced original timestep indices.

For example, `space_timesteps(10, [5])` should return `{0, 2, 4, 7, 9}`, and `space_timesteps(12, [3, 3])` should return `{0, 2, 5, 6, 8, 11}`. If `section_counts` is a comma-separated string such as `"5"`, it should be parsed the same way as the corresponding integer list. If `section_counts` is a DDIM-style string like `"ddim5"`, the function should find an integer stride through `range(0, num_timesteps, stride)` that produces exactly that many timesteps, so `space_timesteps(10, "ddim5")` returns `{0, 2, 4, 6, 8}`.

Invalid requests should fail with `ValueError`: for example, `space_timesteps(4, [5])` should raise because a section cannot provide more timesteps than it contains, and `space_timesteps(10, "ddim7")` should raise because no integer stride yields exactly seven timesteps. Calling the function repeatedly with the same inputs should return the same set, should not mutate a list passed as `section_counts`, and should not perform filesystem, network, or global-state side effects.
