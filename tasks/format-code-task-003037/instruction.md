I want the `elastalert` CLI to support manually silencing a single rule for a fixed duration. When I run `elastalert --config config.yaml --rule noisy_rule.yaml --silence hours=4`, ElastAlert should load that rule, write a silence entry for the rule until four hours from now, log a success message like `Success. <rule name>._silence will be silenced until <timestamp>`, exit with status 0, and not start the normal scheduler loop.

The command should fail fast with status 1 for invalid usage. Running `elastalert --silence hours=4` without `--rule` should log `--silence must be used with --rule`. Running with both `--debug` and `--silence` should log `--silence not compatible with --debug`. If the duration cannot be parsed, for example `elastalert --rule noisy_rule.yaml --silence bananas`, it should log `bananas is not a valid time period`. If the silence cannot be written to Elasticsearch, it should log `Failed to save silence command to Elasticsearch` and exit with status 1.
