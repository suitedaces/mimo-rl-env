If one file contains two top-level tests, both should be available as separate metadata items.

YAML variable rendering should use the selected context gateway by default. If a test body includes a `gateway` field such as `gateway: secondary`, rendering should use variables from that gateway instead, and quoted or escaped gateway values like `gateway: "secon\\tdary"` should be parsed as YAML so they match the configured gateway name exactly.
