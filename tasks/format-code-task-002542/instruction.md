I want ftfy to support a pure curly-quote cleanup feature. The direct API should be `ftfy.fixes.uncurl_quotes(text: str) -> str`, returning a new string where curly single quotation marks and modifier-letter apostrophes are replaced with ASCII `'`, and curly double quotation marks are replaced with ASCII `"`. For example, `uncurl_quotes('“here’s a test”')` should return `'"here\'s a test"'`, and `uncurl_quotes('lʼamour ‘quoted’ ‟word‟')` should return `'l\'amour \'quoted\' "word"'`.

The same cleanup should run as part of `ftfy.fix_text`, `ftfy.fix_text_segment`, `ftfy.fix_file`, and `ftfy.fix_and_explain` by default through a boolean `uncurl_quotes` option on `TextFixerConfig` and equivalent keyword arguments. `fix_text('it’s fine')` should return `"it's fine"`, while `fix_text('it’s fine', uncurl_quotes=False)` and `fix_text('it’s fine', TextFixerConfig(uncurl_quotes=False))` should preserve the curly apostrophe. When explanations are enabled, `fix_and_explain('it’s fine')` should include an `('apply', 'uncurl_quotes')` step only when this cleanup changes the text, and `apply_plan('it’s fine', [('apply', 'uncurl_quotes')])` should produce `"it's fine"`. Repeated calls with the same input should return the same output, the input string should not be mutated, and the function should not read or write files, use the network, or rely on hidden global state.
