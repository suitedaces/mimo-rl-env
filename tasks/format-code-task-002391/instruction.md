I want the `Auditor` library API to collapse duplicate vulnerability advisories while producing audit results. A user should be able to construct it as `Auditor(service, options=AuditOptions())` and call `audit(source)`, where `source.collect()` supplies dependencies and `service.query_all(...)` returns `(dependency, vulnerabilities)` pairs.

When two `VulnerabilityResult` objects for the same dependency share any identifier between their primary `id` and their `aliases`, `audit(source)` should emit only one vulnerability for that advisory. If one of the duplicates has a primary id beginning with `PYSEC`, that `PYSEC` result should be the emitted result regardless of the provider order. The emitted result should preserve the complete alias set by merging aliases from the duplicate records while keeping its own primary id out of its alias set.

For example, if the service returns `PYSEC-0` with aliases `{CVE-2024-0001}` and `GHSA-aaaa` with aliases `{CVE-2024-0001, GHSA-aaaa}`, `list(auditor.audit(source))` should contain one vulnerability for that dependency with id `PYSEC-0` and aliases including both `CVE-2024-0001` and `GHSA-aaaa`. If the service returns `PYSEC-0` aliased to `CVE-2024-0001`, `GHSA-aaaa` aliased to `CVE-2024-0001`, and a third result whose primary id is `CVE-2024-0001` and alias is `GHSA-aaaa`, the audit result should still contain a single vulnerability with id `PYSEC-0` and the merged aliases.
