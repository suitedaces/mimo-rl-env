I want `erys` to support opening and saving Jupyter notebook files through its terminal app. When I run `erys analysis.ipynb` and `analysis.ipynb` is a non-empty nbformat JSON notebook, the notebook tab should read the file, create editable code and markdown cells for the entries in `cells`, preserve their order, and start focus on the first loaded cell. If the notebook file is empty, opening it should leave the notebook empty without crashing.

When the app saves a notebook to a path, it should write valid JSON to that path with top-level `metadata`, `nbformat`, `nbformat_minor`, and `cells` fields. The saved metadata should include `kernel_info`, `kernel_spec`, and `language_info`, and the `cells` array should contain one entry for each current notebook cell in the same order shown in the editor. If an opened `.ipynb` file cannot be decoded as JSON, the app should notify the user that `<path> is not a valid notebook. Failed to decode JSON.` and close that broken notebook tab instead of leaving it open.
