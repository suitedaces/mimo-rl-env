I want MMSegmentation to provide a `SegFormerHead` decode head that I can select in a model config with `decode_head=dict(type='SegFormerHead', ...)` or construct directly as `SegFormerHead(feature_strides, **kwargs)`. The constructor should accept four feature strides, four input channel counts, four input indices, a class count, and `decoder_params={'embed_dim': <int>}` along with the normal decode-head options. It should validate that `len(feature_strides) == len(in_channels)` and that the first stride is the smallest stride, raising `AssertionError` when either rule is violated.

The public `forward(inputs)` method should consume the four selected backbone feature tensors from a SegFormer encoder and return dense class logits at the spatial resolution of the finest selected feature. For example, with `num_classes=19`, `feature_strides=[4, 8, 16, 32]`, `in_channels=[32, 64, 160, 256]`, and input tensors shaped `(2,32,128,128)`, `(2,64,64,64)`, `(2,160,32,32)`, and `(2,256,16,16)`, `forward(inputs)` should return a tensor shaped `(2,19,128,128)`. With `num_classes=150`, `in_channels=[64, 128, 320, 512]`, and one-image inputs shaped `(1,64,64,64)`, `(1,128,32,32)`, `(1,320,16,16)`, and `(1,512,8,8)`, the returned logits should have shape `(1,150,64,64)`.

Each of the four scales should be projected into the configured embedding dimension, the three coarser scales should be bilinearly resized to the finest feature resolution with `align_corners=False`, all four projected scales should be concatenated and fused, and the final output should contain one score channel per semantic class. Separate `SegFormerHead` instances should own separate PyTorch parameters, so mutating or training one instance must not change another instance.
