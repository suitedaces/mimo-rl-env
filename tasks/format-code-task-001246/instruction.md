I want solution phases to expose endmember activities and activity coefficients after I set their composition and pressure-temperature state. For an existing `Solution` object, `solution.activities` should return a unitless array computed from `solution.pressure`, `solution.temperature`, and `solution.molar_fractions`, and `solution.activity_coefficients` should return the corresponding unitless gamma values. The underlying solution models should also provide `activities(pressure, temperature, molar_fractions)` and `activity_coefficients(pressure, temperature, molar_fractions)` public methods.

For a `MechanicalSolution` with two endmembers, calling either model method with `pressure=1.0e9`, `temperature=1000.0`, and `molar_fractions=np.array([1.0, 0.0])` should return `np.array([1.0, 1.0])`. For an ideal olivine-style solution with endmember site formulae `[Mg]2SiO4` and `[Fe]2SiO4`, after `set_composition(np.array([0.5, 0.5]))` and `set_state(1.0e5, 1000.0)`, `activities` should be `[0.25, 0.25]` and `activity_coefficients` should be `[1.0, 1.0]`. For a Temkin-style ideal model with multi-site endmember formulae, `activities` should equal `np.exp(-solution.excess_partial_entropies / burnman.constants.gas_constant)` at the current composition.

For non-ideal regular, subregular, function-based, and polynomial solution models, `activity_coefficients(pressure, temperature, molar_fractions)` should be the exponential of the non-configurational excess partial Gibbs-energy contribution for each endmember divided by `R * temperature`, where `R` is `burnman.constants.gas_constant`. `activities(...)` should multiply the ideal activities by those coefficients. For example, in the orthopyroxene two-endmember regular-solution case at composition `np.array([0.0, 1.0])`, `pressure=1.0e5`, and `temperature=1000.0`, `activity_coefficients` should be `[np.exp(1.0), 1.0]`. If a non-ideal model is asked for activity coefficients at `temperature <= 1.0e-10`, it should raise `Exception("Activity coefficients not defined at 0 K.")`.
