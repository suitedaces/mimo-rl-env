I want `AtomTyper.get_typer(prop_funcs='oadc', radius_func=1.0, rec=False, device='cuda') -> AtomTyper` as a pure factory for building configured atom typers from compact property and radius codes. For `AtomTyper.get_typer('oadc', 1.0, rec=False, device='cpu')`, `list(typer.get_type_names())` should be `['atomic_num=5', 'atomic_num=6', 'atomic_num=7', 'atomic_num=8', 'atomic_num=9', 'atomic_num=15', 'atomic_num=16', 'atomic_num=17', 'atomic_num=35', 'atomic_num=53', 'atomic_num=26', 'aromatic=0', 'aromatic=1', 'h_acceptor=1', 'h_donor=1', 'formal_charge=-1', 'formal_charge=0', 'formal_charge=1']`, `typer.n_types` should be 18, and `typer.get_radius(atom)` should return 1.0 for any atom. For `AtomTyper.get_typer('', 1.0, rec=True, device='cpu')`, the element channels should be receptor elements only: `['atomic_num=6', 'atomic_num=7', 'atomic_num=8', 'atomic_num=11', 'atomic_num=12', 'atomic_num=15', 'atomic_num=16', 'atomic_num=17', 'atomic_num=19', 'atomic_num=20', 'atomic_num=30']`. If `prop_funcs` contains `h`, hydrogen should be inserted as the first element channel and `typer.explicit_h` should be true; for example `AtomTyper.get_typer('hn', 2.5, rec=False, device='cpu')` should have `atomic_num=1` first, include hydrogen-count channels `h_count=0` through `h_count=4`, and use fixed radius 2.5. The radius code `'v'` should use van der Waals radii and `'c'` should use covalent radii. `AtomTyper.get_default_rec_typer(device='cpu')` and `AtomTyper.get_default_lig_typer(device='cpu')` should be shortcuts for the default `'oadc'` receptor and ligand factories, and `DefaultRecTyper` / `DefaultLigTyper` should be callable aliases exported from both `ligan.atom_types` and top-level `ligan`. Passing an invalid `prop_funcs` value such as `None` should raise `TypeError` instead of returning a partial typer. Calling the factory twice with the same arguments should produce equivalent independent typers and should not mutate inputs, touch the filesystem, use the network, or alter module-level defaults.
