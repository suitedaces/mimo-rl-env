I want PyOTI to provide a `CheckDMARC` domain checker that I can import with `from pyoti.domains import CheckDMARC`. It should be usable as `checker = CheckDMARC(domain: str = None)`, with `checker.check_domain() -> dict` performing DNS TXT lookups for the domain and `_dmarc.<domain>`, and `checker.query_txt(name: str)` returning TXT records or an empty list when the DNS lookup fails.

`check_domain()` should return a dictionary with exactly the domain being checked, the discovered DMARC record, the discovered SPF record, and a boolean `spoofable` result. For example, if `example.com` has SPF TXT `v=spf1 include:_spf.example.com -all` with TTL 300 and `_dmarc.example.com` has TXT `v=DMARC1; p=reject; rua=mailto:dmarc@example.com` with TTL 600, `CheckDMARC("example.com").check_domain()` should return `{"domain": "example.com", "dmarc": {"txt": "v=DMARC1; p=reject; rua=mailto:dmarc@example.com", "ttl": 600}, "spf": {"txt": "v=spf1 include:_spf.example.com -all", "ttl": 300}, "spoofable": False}`. If the same domain has the SPF record but no DMARC TXT record, it should return the SPF record, an empty DMARC dictionary, and `spoofable: True`. If DMARC exists with `p=none`, or the SPF record does not end in `-all` or `~all`, the result should also mark the domain as spoofable.
