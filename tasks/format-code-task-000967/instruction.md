Add an options flow to the existing VoIP config entry with allowed_networks and blocked_networks lists. Items may be IPv4 or IPv6 hosts or CIDRs and are saved as canonical network strings, de-duplicated in first-seen order. Invalid items keep the form open, report invalid_network on the offending field, and leave prior options unchanged. An empty allow list admits any address; a non-empty allow list admits only matching callers. Any blocked match is always rejected, including with an empty allow list, and blocking wins over allowing. Apply admission before device lookup or creation so rejected callers create no registry entries or entities. Admitted callers still require the existing per-device Allow calls switch, retaining default-off and optionless-entry compatibility. Saving options applies to subsequent calls while preserving known devices and leaving the integration loaded. Support both IPv4 and IPv6 callers.
