I want retry attempt helpers in the core `lo` package so I can call a callback repeatedly until it succeeds, exhausts a retry limit, or asks to stop.

Please provide `func Attempt(maxIteration int, f func(index int) error) (int, error)`. It should call `f` with zero-based attempt indexes, stop on the first nil error, and return the 1-based number of invocations plus nil. For example, if `f` returns an error for indexes 0 through 4 and nil at index 5, `Attempt(42, f)` should return `(6, nil)`. If every invocation fails for `Attempt(2, f)`, it should return `(2, lastErr)`. If `maxIteration < 1`, it should keep trying until the callback returns nil, so a callback that fails while `i < 42` and then succeeds should make `Attempt(0, f)` return `(43, nil)`.

Please also provide `func AttemptWithDelay(maxIteration int, delay time.Duration, f func(index int, duration time.Duration) error) (int, time.Duration, error)`. It should have the same success, exhaustion, and unlimited-attempt behavior as `Attempt`, pass the elapsed duration since the helper started into every callback invocation, sleep for `delay` after each failed attempt that will be followed by another attempt, and return the final elapsed duration. For example, with a 10ms delay and success at index 3, it should invoke the callback 4 times and return an elapsed duration around 30ms; with `maxIteration == 2` and both attempts failing, it should invoke the callback twice, sleep once, and return the last error.

Please provide `func AttemptWhile(maxIteration int, f func(int) (error, bool)) (int, error)`. It should retry like `Attempt`, but the callback's boolean decides whether another invocation is allowed. If the callback returns `continue == false`, the helper should return immediately with the current invocation count and the current error, even when the error is nil. For example, if indexes 0 through 4 return `(err, true)` and index 5 returns `(nil, false)`, `AttemptWhile(0, f)` should return `(6, nil)`; if the callback returns `(nil, false)` at index 0, it should return `(1, nil)`.

Please provide `func AttemptWhileWithDelay(maxIteration int, delay time.Duration, f func(int, time.Duration) (error, bool)) (int, time.Duration, error)`. It should combine the early-stop boolean behavior of `AttemptWhile` with the elapsed-duration argument and inter-attempt sleeps of `AttemptWithDelay`. For example, with a 10ms delay and a callback that fails with `continue == true` through index 2 then returns `(nil, false)` at index 3, it should return 4 invocations, nil error, and elapsed duration around 30ms. When a bounded run exhausts its attempts while the callback keeps returning an error and `continue == true`, it should return the max attempt count, the elapsed duration including sleeps between attempts, and the final error.
