I want a started `pyrogram.Client` instance to expose an async `invoke(query: TLObject, retries: int = Session.MAX_RETRIES, timeout: float = Session.WAIT_TIMEOUT, sleep_threshold: float | None = None)` method for manually calling raw Telegram API functions. For example, after `await app.start()`, `await app.invoke(raw.functions.updates.GetState())` should send that raw function through the client's active session and return the raw response object produced by Telegram.

Calling `await app.invoke(...)` before the client is connected should raise `ConnectionError` with the message `Client has not been started yet`. If the client was created with updates disabled, the method should wrap the raw function in `raw.functions.InvokeWithoutUpdates` before sending it. If the client is currently using a takeout session, it should wrap the raw function in `raw.functions.InvokeWithTakeout` using the client's active takeout id. The method should pass the provided `retries` and `timeout` values to the session invocation, and should use the explicit `sleep_threshold` when one is supplied or the client's configured sleep threshold when it is `None`.

When the raw response contains `users` or `chats` collections, the client should update its peer cache from those collections before returning the response. Exceptions raised while the session invokes the raw function should propagate to the caller.
