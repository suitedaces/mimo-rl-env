I want the GATT service tree exposed from a connected `BleakClient` to provide lookup helpers for discovered services, characteristics, and descriptors after connection. In a session like `async with BleakClient(device) as client: services = client.services`, the `services` object should support `services.get_service(specifier)`, `services.get_characteristic(specifier)`, `services.get_descriptor(handle)`, and `services[specifier]`; individual service objects should support `service.get_characteristic(uuid)`, and characteristic objects should support `characteristic.get_descriptor(specifier)`.

`services.get_service()` should accept an integer handle, a UUID string, or a `uuid.UUID`; return the matching service; return `None` when nothing matches; and raise `BleakError` when a UUID matches more than one service so callers know to use a handle. `services.get_characteristic()` should have the same handle/UUID/`uuid.UUID` behavior for characteristics, including returning `None` for no match and raising `BleakError` when a UUID is ambiguous. `services.get_descriptor(handle)` should look up descriptors by integer handle and return `None` when the handle is unknown.

`services[specifier]` should resolve a specifier against services first, then characteristics, then descriptors, returning the first matching object or `None`. `service.get_characteristic(uuid)` should normalize UUID strings and return the first characteristic in that service with the requested UUID, or `None` if it is absent. `characteristic.get_descriptor(specifier)` should accept a descriptor handle, UUID string, or `uuid.UUID`, normalize UUID strings for matching, and return the matching descriptor or `None` when it is absent.
