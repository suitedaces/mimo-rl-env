The measurement helpers expose unit constants for more units than they can currently convert, which causes integrations to silently keep values in the wrong units. Complete the public conversion surface used by Home Assistant. `UnitSystem` must provide mass conversion with the same numeric validation and configured-target semantics as its other measurement methods. Distance conversion must support every length unit represented by the constants (centimeters, meters, kilometers, inches, feet, yards, and miles) in both directions, using the ordinary SI/US relationships. Volume conversion must convert liters, milliliters, gallons, and fluid ounces in every direction; retain the existing 1 gallon = 3.785 liters convention and use 1 fluid ounce = 0.0295735 liters. Pressure conversion must support the declared bar unit alongside the existing pressure units, with 1 bar = 100000 Pa. Mass conversion should use 1000 grams per kilogram, 453.59237 grams per pound, and 28.349523125 grams per ounce. Conversions must preserve identity and zero values, use stable floating-point results, and reject nonnumeric values or unknown units with the established exception types. Keep existing temperature, distance, volume, pressure, and unit-system behavior compatible while extending these missing paths.
