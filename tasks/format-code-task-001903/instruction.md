I want the `go-micro.dev/v6/gateway/a2a` package to provide a stateful outbound A2A client for calling remote agents by URL. The constructor should be `func NewClient(url string) *Client`, where `url` is the remote agent's JSON-RPC endpoint, and each new client should use an HTTP client with a 60 second timeout by default.

The returned `*Client` should support `WithHTTPClient(h *http.Client) *Client`; passing a non-nil client replaces the transport for that client instance and returns the same `*Client` for chaining, while passing nil leaves the existing transport unchanged. It should also support `Card(ctx context.Context) (*AgentCard, error)`, which fetches `<url>/.well-known/agent.json`, decodes a 200 JSON response into an `AgentCard`, and returns an error like `agent card: status 404` for non-200 responses.

The client should support `Send(ctx context.Context, text string) (string, error)`. `Send` should POST a JSON-RPC 2.0 `message/send` request to `url` with a user text message, then return the final text response. If the remote result is a message with text parts, `Send(ctx, "hi")` should return the concatenated text from those parts, such as `"hello"`. If the remote result is a task in `completed` state with text artifacts, `Send(ctx, "ping")` should return the concatenated artifact text, such as `"pong"`.

When the first task response is not terminal, `Send` should poll JSON-RPC `tasks/get` with that task id about every 300 milliseconds until the task reaches a terminal state or the context is done. If polling reaches a completed task, return its artifact text; if it reaches a failed, canceled, or rejected task, return an error like `remote task <id> ended in state "failed"`. If the remote JSON-RPC response contains an error object, return an error that includes the A2A method name, the remote error message, and the numeric error code, for example `a2a message/send: bad request (-32602)`. Two `Client` instances should keep independent URLs and HTTP transports so configuring one with `WithHTTPClient` does not affect the other.
