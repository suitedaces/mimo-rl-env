I want the normal movie packaging command to carry matching subtitle files into the organized output alongside the movie. When I run `python Movie_Data_Capture.py /media/ABP-123.mp4 -m 1 -n ABP-123 -L 0` and `/media/ABP-123.srt` exists with `.srt` included in the public `sub_type` config, the run should move that subtitle into the generated movie folder as `ABP-123.srt` and print `[+]Sub Moved!        ABP-123.srt`. In link mode, for example `python Movie_Data_Capture.py /media/ABP-123.mp4 -m 1 -n ABP-123 -L 1`, the subtitle should be copied instead of moved and stdout should include `[+]Sub Copied!       ABP-123.srt`.

The same subtitle carry-over should happen in organizing mode with `-m 2` after the movie file is placed in its target folder. Subtitle matching should only use files whose suffix is allowed by `sub_type`, whose base name matches the movie base name before any dot-separated suffixes, and, for multi-part files such as `ABP-123-CD2.mp4`, whose subtitle filename includes the same `-CD2` part marker. If the carried subtitle has multiple suffixes such as `ABP-123.zh.srt`, the output filename should preserve them as `ABP-123.zh.srt`. If no allowed matching subtitle exists, the packaging run should continue without printing a subtitle moved/copied line.
