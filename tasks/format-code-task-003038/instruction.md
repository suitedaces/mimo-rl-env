I want `from nlg_yongzhuo import mmr` to expose a summarizer that returns a non-redundant ranking of sentences from either a raw text string or a list of sentences. It should accept `summarize(text, num=8, alpha=0.6)` and return `(score, sentence)` pairs sorted from highest score to lowest score, limited to `num` results.

The `alpha` weight should control the tradeoff between sentence importance and redundancy, so higher values favor relevance and lower values favor diversity. If the input is not a string or a sentence list, it should raise `RuntimeError` instead of coercing it. Repeated sentence text should not appear more than once in the ranking, and the same input should produce the same output without mutating the caller’s data. I also want the package's merged `text_summarize(...)` helper to include this summarizer in its default feature set.
