I want a pure JavaScript function `extractTagContent(text: string, rules: Array<{type: string, value: string, enabled: boolean}>, blacklist?: string[]) -> string` that turns raw chat/message text into the exact text that should be vectorized.

If `rules` is empty or missing, it should return the original `text` unchanged. Enabled `exclude` rules should run first and remove whole XML-like blocks such as `<thinking>...</thinking>` before anything is collected. Enabled `include` rules should collect content from matching `<tag>...</tag>` blocks and from brace-pipe blocks like `{tag|...}`, preserving nested braces inside the brace-pipe content. Enabled `regex_include` rules should collect the first capture group from each match. Enabled `regex_exclude` rules should then clean each collected block, and any block containing a blacklist keyword case-insensitively should be dropped. The return value should join surviving blocks with blank lines and collapse excessive blank lines at the end.

For example, `extractTagContent('raw <content>Hello</content>', [], [])` should return `'raw <content>Hello</content>'`. For `extractTagContent('intro <thinking>hide</thinking> <content>Hello [draft]</content> {content|Second {nested} part} <content>Skip secret</content>', [{type:'exclude', value:'thinking', enabled:true}, {type:'include', value:'content', enabled:true}, {type:'regex_exclude', value:'\\s*\\[draft\\]', enabled:true}], ['secret'])`, it should return `'Hello\n\nSecond {nested} part'`. For `extractTagContent('A [[keep one]] B [[keep two]]', [{type:'regex_include', value:'\\[\\[(.*?)\\]\\]', enabled:true}], [])`, it should return `'keep one\n\nkeep two'`.

Malformed enabled rule patterns should not make the function throw; the bad rule should be skipped while other valid enabled rules still apply. Repeated calls with the same inputs should return the same string, the input string/rules/blacklist arrays should not be mutated, and the function should not perform filesystem or network work.
