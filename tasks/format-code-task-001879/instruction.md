I want `cssua.format(ua: Object) -> string` to turn a normalized user-agent map into the CSS class-name string that page authors can apply to the HTML element. The function should be pure: calling it repeatedly with the same object gives the same string, it does not mutate the object, and it does not read or write the filesystem, network, DOM, or other global state.

For `{windows_nt: '5.0', os: 'windows', ie: '5.5'}`, it should return ` ua-windows_nt ua-windows_nt-5 ua-windows_nt-5-0 ua-os ua-os-windows ua-ie ua-ie-5 ua-ie-5-5`. For `{gecko: '1.9.2.13', firefox: '3.6.13'}`, it should return ` ua-gecko ua-gecko-1 ua-gecko-1-9 ua-gecko-1-9-2 ua-gecko-1-9-2-13 ua-firefox ua-firefox-3 ua-firefox-3-6 ua-firefox-3-6-13`.

Each own enumerable key should always emit a base class with the `ua-` prefix and a leading space, such as ` ua-standalone` for `{standalone: true}`. When a value is a string, spaces in the value become underscores, dots in keys and values become hyphens, and progressively specific version classes are included at each hyphen boundary before the full value. Inherited properties should not produce classes, and an empty object should return an empty string.
