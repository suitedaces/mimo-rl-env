I want `solana.Transaction` to provide a stateful signing and signature verification API. On a `*Transaction`, `PartialSign(func(solana.PublicKey) *solana.PrivateKey) ([]solana.Signature, error)` should serialize the transaction message, use the message's required signer public keys in order, allocate `tx.Signatures` to that signer count when it is empty, and write signatures only for keys whose callback returns a non-nil private key; nil keys should leave existing or zero signature slots untouched so repeated partial signing calls can fill signer slots in any order.

For a transaction with three required signers A, B, and C and an empty `Signatures` slice, calling `PartialSign` with only B's key should return a 3-element slice, set `Signatures[1]` to B's signature, leave `Signatures[0]` and `Signatures[2]` as zero signatures, and a later call with A and C should fill slots 0 and 2 without moving B. If `tx.Signatures` already has a nonzero length different from the required signer count, `PartialSign` should return an error like `invalid signatures length, expected 3, actual 1` and should not resize it.

`Sign(func(solana.PublicKey) *solana.PrivateKey) ([]solana.Signature, error)` should require every signer key before signing. For a transaction with signers A and B, if the callback returns A's key but nil for B, `Sign` should return a non-nil error mentioning B and should not silently produce a partially signed transaction; when the callback returns both keys, it should fill `tx.Signatures` in signer order and return that same slice.

`VerifySignatures() error` should serialize `tx.Message`, require `len(tx.Signatures) == len(tx.Message.Signers())`, and verify each signature against the public key at the same signer index. After `Sign` succeeds, `VerifySignatures` should return nil. If a transaction has two required signers but only one stored signature, `VerifySignatures` should return an error like `got 2 signers, but 1 signatures`; if a signature slot contains a signature made by the wrong key or over different message bytes, it should return an error identifying the invalid signer.
