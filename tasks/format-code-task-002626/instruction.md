I want a Python helper `calculate_formula(formula="", parameters={}, imports=None)` in the calculation module that evaluates a SENAITE calculation formula and returns the computed value directly. The formula should use square-bracket placeholders, so `calculate_formula("[Ca] + [Mg]", {"Ca": 5, "Mg": 3})` returns `8`, and it should tolerate formatting whitespace by stripping newlines, tabs, and carriage returns before evaluation.

The helper should also support dotted placeholder names and string values supplied by the caller, for example `calculate_formula("[Comment] if [Comment] == 'uncertain' else ([Ca] + [Mg])", {"Comment": "'uncertain'", "Ca": 5, "Mg": 5})` returns `'uncertain'`. When `imports` is a list like `[{"module": "math", "function": "floor"}]`, the named member should be available in the formula, so `calculate_formula("floor([Ca] + [Mg])", {"Ca": 5.6, "Mg": 3.3}, [{"module": "math", "function": "floor"}])` returns `8.0`.

Known evaluation failures should be converted into result strings instead of escaping as exceptions: a missing placeholder returns `"Key Error: <name>"`, division by zero returns a string beginning with `"Division by 0: "`, a missing imported function returns `"Import Error: Could not find member <function> of module <module>"`, and syntax problems return a string beginning with `"Syntax Error: "`. Repeating the call with the same arguments should produce the same result, and the function should not mutate the supplied `parameters` or `imports` objects.
