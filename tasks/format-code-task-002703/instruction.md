I want spew's one-shot formatting APIs `Sdump(a ...interface{}) string`, `Sprintf(format string, a ...interface{}) string`, and `NewFormatter(v interface{}) fmt.Formatter`, including the matching `*ConfigState` methods and print/writer wrappers, to render a value through its Go `fmt.Stringer` or `error` method when that method is available.

Assuming the sample types below are declared in package `main`, for `type ID string` with `func (v ID) String() string { return "id=" + string(v) }`, `spew.Sprintf("%v", ID("a7"))` should return `id=a7`, `spew.Sprintf("%#v", ID("a7"))` should return `(main.ID)id=a7`, and `spew.Sdump(ID("a7"))` should return `(main.ID) (len=2) id=a7\n`. For `type Code int` with `func (c Code) Error() string { return fmt.Sprintf("code %d", c) }`, `spew.Sprintf("%v", Code(5))` should return `code 5` and `spew.Sdump(Code(5))` should return `(main.Code) code 5\n`.

`ConfigState` should expose `DisableMethods`, `DisablePointerMethods`, and `ContinueOnMethod`. With `ConfigState{DisableMethods: true}`, method text is not invoked, so `cfg.Sprintf("%v", ID("a7"))` returns the underlying string `a7`. When unsafe reflection is available, a non-pointer value whose `String()` exists only on `*T` should still use that pointer-receiver method by default; setting `DisablePointerMethods: true` should make that same non-pointer value print through its underlying reflected value instead.

When `ContinueOnMethod` is true for a struct such as `type Box struct { N int }` with `func (b Box) String() string { return fmt.Sprintf("box:%d", b.N) }`, `ConfigState{Indent: " ", ContinueOnMethod: true}.Sdump(Box{N: 2})` should include both the method text and the struct internals, exactly `(main.Box) (box:2) {\n N: (int) 2\n}\n`. If a `String()` or `Error()` method panics, the formatting call itself should not panic; for `type Bad int` whose `String()` panics with `boom`, `spew.Sprintf("%v", Bad(9))` should return `(PANIC=boom)9`.

The same method text should be usable for deterministic map-key ordering when `SortKeys` is true: for a struct key type whose `String()` returns `a` or `b`, `ConfigState{SortKeys: true}.Sprintf("%v", map[Key]int{Key{"b"}: 2, Key{"a"}: 1})` should return `map[a:1 b:2]`. In dump-style output, slices or arrays whose element type is a custom `uint8` alias implementing `String()` should print each element using that method instead of choosing the hexdump path while methods are enabled; with `DisableMethods: true`, the same byte-like data can fall back to hexdump formatting.
