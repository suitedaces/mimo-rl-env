I want `XcodeProject.add_file(path, parent=None, tree=TreeType.SOURCE_ROOT, target_name=None, force=True, file_options=FileOptions())` to support duplicate-safe insertion when `force=False`. In a session where I load a project and `file.m` is already present in the selected target's build phases, calling `project.add_file("file.m", target_name="app", force=False)` should return `[]` and should not create another `PBXFileReference` or `PBXBuildFile` for that target. If I call `project.add_file("file.m", target_name=["app", "report"], force=False)` and only `app` already contains `file.m`, the method should add the file only to `report` and return the build file objects created for `report`; the existing `app` membership should be left unchanged. The duplicate check should compare the leaf filename of the requested path against each existing build file's referenced path, so an existing reference like `Sources/file.m` should make `project.add_file("file.m", force=False)` skip that target.
