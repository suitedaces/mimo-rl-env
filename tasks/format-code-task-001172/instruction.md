Transaction bundles assembled by package importers and other clients often use `Bundle.entry.fullUrl` URNs and anonymous resources, but `BundleUtil.sortEntriesIntoProcessingOrder` currently assumes usable resource IDs. This can lose or duplicate entries, miss real dependencies, report false cycles, and make independent entries move unpredictably. Make this public in-place sorter robust and deterministic for R4 transaction bundles without changing its signature.

Treat an entry's nonblank `fullUrl` and its resource ID, when present, as aliases for that entry. Internal references must resolve against exact `urn:uuid:` full URLs and against relative or absolute FHIR identities; `_history/{version}` suffixes on an entry identity or reference do not distinguish resources. Only references that identify another entry in the same bundle create an ordering dependency. References to the entry itself, contained references beginning with `#`, and references outside the bundle create no dependency and must not cause a cycle.

Keep the operation-phase order DELETE, POST, PUT, then all remaining request methods. Within POST and PUT, every referenced entry in the same phase must precede the entry that references it. Within DELETE, reverse that dependency direction so dependents are deleted before the entries they reference. When multiple entries in one phase are eligible for the next output position, choose the one that appeared earliest in the original bundle; this also applies to entries with no resource. Applying the sorter again must produce the same sequence. Every original `BundleEntryComponent` must remain present exactly once as the same component object; sorting changes only the entry sequence.

If two or more distinct entries in one operation phase form a dependency cycle, throw `IllegalStateException` with a message containing `cycle` and leave the bundle's entry sequence unchanged. Preserve the established resource-ID-based dependency sorting, version-insensitive cycle detection, operation precedence, and support for DELETE entries without resources.
