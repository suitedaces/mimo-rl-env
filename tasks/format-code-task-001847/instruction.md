I want a stateful `List` widget for tui-go that I can create with `NewList() *List` and use as a normal `Widget`. A new list starts empty with no selection, so `Selected()` returns `-1`; after `AddItems("one", "two", "three")`, `Length()` returns `3`, `SizeHint()` reports the width of the widest item and the number of items, and `Draw` paints the item strings one per row.

The list should expose `AddItems(items ...string)`, `RemoveItem(i int)`, `RemoveItems()`, `Length() int`, `SetSelected(i int)`, `Selected() int`, `Select(i int)`, and `SelectedItem() string`. `SetSelected(1)` should make `Selected()` return `1` and `SelectedItem()` return the second item. `Select(i)` should update the selected index and call the function registered with `OnSelectionChanged(func(*List))`; `SetSelected(i)` should only change the index.

When the list is focused and receives `OnKeyEvent(KeyEvent{Key: KeyDown})` or `OnKeyEvent(KeyEvent{Rune: 'j'})`, selection moves down by one until it reaches the last item. `KeyUp` and rune `'k'` move up until index `0`. These movement keys should call the selection-changed callback even when the selection is already at an edge, while events sent to an unfocused list should not change selection. When the focused list receives `KeyEnter`, it should call the callback registered with `OnItemActivated(func(*List))`.

Removing items should keep selection consistent. `RemoveItems()` clears the list, resets selection to `-1`, and fires the selection-changed callback. `RemoveItem(i)` removes only that item, shifts later items forward for drawing and indexing, clears selection to `-1` if the removed item was selected, decrements the selected index if a prior item was removed, and fires the selection-changed callback.

For rendering, unselected rows should use the `list.item` style, the selected row should use `list.item.selected`, and the default theme should make `list.item.selected` visibly reversed. Each drawn row should fill the list width before writing the item text, so highlighted selection covers the whole row.
