I want a stateful `WX.NoteClip()` API for managing a collection of `WX.Note` objects in browser-side WAAX code. A session should look like `var clip = WX.NoteClip(); var id = clip.push(WX.Note(60, 64, 0, 120)); clip.get(id)` and `get(id)` should return the same note object while `getSize()` reports `1` and `hasId(id)` reports `true`.

`push(note)` should assign a unique string ID that does not collide with IDs already in that clip, store the note under that ID, increment the clip size, and return the ID. `delete(id)` should remove and return the stored note when the ID exists, decrementing the size; deleting a missing ID should return `null` and leave the clip unchanged. `empty()` should remove all notes and make `getSize()` return `0`.

I need lookup and selection helpers for piano-roll editing. `findNoteIdAtPosition(pitch, tick)` should return the ID of a note whose pitch matches and whose tick falls inclusively between `note.start` and `note.getEnd()`, or `null` if there is no match. `findNotesIdInArea(minPitch, maxPitch, startTick, endTick)` should return an array of IDs whose note pitch and note start are within the inclusive ranges, or `null` when none match. `scanNotesInTimeSpan(start, end)` should return the matching note objects whose start tick is within the inclusive range, or `null` when none match.

The clip also needs `getAllId()` to return all stored note IDs, `set(id, note)` to update an existing note by copying properties through the note API and to make an absent ID retrievable with that note, and `iterate(callback)` to call `callback(id, note, index)` once for each stored note in the clip. Two independent `WX.NoteClip()` instances should keep separate note stores and sizes.
