I want object-manager containers to expose a stateful `manage_clone(ob, id, REQUEST=None)` method. In a session, after `dest.manage_clone(src_doc, "doc_copy")`, the method should return the new cloned object and `dest` should contain that returned object under the id `doc_copy`; `src_doc` should still remain in its original container. The cloned object should have the requested id, be inserted through the container's normal object-add behavior, and emit the normal copy lifecycle: an object-copied notification before insertion and an object-cloned notification after insertion, with the `manage_afterClone` compatibility hook called for the clone. If `ob.cb_isCopyable()` is false, it should raise `CopyError("Not Supported")`; if the requested id is invalid for the destination container, it should raise `CopyError("Invalid Id")`; if the source object rejects the clone during its copy notification step, it should raise `CopyError("Clone Error")` while preserving conflict errors. The method should verify that the current user may paste that object type into the destination before copying, and it should never move or rename the source object.
