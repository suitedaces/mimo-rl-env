I want zerolog to support stateful log sampling that can be attached to a logger before events are emitted. The API should include `type Sampler interface { Sample(Level) bool }`, `func (l Logger) Sample(s Sampler) Logger`, and the global convenience `func Sample(s zerolog.Sampler) zerolog.Logger` in the `github.com/rs/zerolog/log` package.

A sampled logger should apply its sampler after normal level filtering and before creating an event: if `Sample(level)` returns false, calls like `log.Log().Int("i", n).Msg("")` should produce no record; if it returns true, the event should be written normally. For example, with `log := zerolog.New(out).Sample(&zerolog.BasicSampler{N: 2})`, four no-level events with `i` values 1, 2, 3, and 4 should write exactly `{"i":1}\n{"i":3}\n`.

I need built-in sampler implementations. `type BasicSampler struct { N uint32 }` should allow every Nth event, returning false when `N == 0`, true for every event when `N == 1`, and true for the 1st, 1+N, 1+2N events when `N > 1`. `type RandomSampler uint32` should randomly allow roughly one event out of N and should reject all events when the value is zero. The package variables `Often`, `Sometimes`, and `Rarely` should be predefined random samplers for about 1-in-10, 1-in-100, and 1-in-1000 events.

I also need burst and level-aware sampling. `type BurstSampler struct { Burst uint32; Period time.Duration; NextSampler Sampler }` should allow up to `Burst` events during each `Period`, then delegate to `NextSampler`, or reject after the burst when `NextSampler` is nil; when `Period == 0` or `Burst == 0`, it should go straight to `NextSampler`. `type LevelSampler struct { TraceSampler, DebugSampler, InfoSampler, WarnSampler, ErrorSampler Sampler }` should use the configured sampler for those levels and allow levels without a configured sampler, including fatal, panic, and no-level events.

Finally, I want `func DisableSampling(v bool)` to act as a process-wide override. When sampling is disabled with `DisableSampling(true)`, a logger configured with a sampler should emit all events that pass normal level filtering; calling `DisableSampling(false)` should make configured samplers active again.
