Update Rule L053 so its public lint and fix APIs reliably remove parentheses that wrap a complete top-level SQL statement, including statements containing comments and statement terminators. A wrapped statement should be reported by L053 and fixing it should preserve the SQL and comments in their original relative order, lift comments out of the wrapper without introducing parser-invalid leading segments, and normalize the wrapper boundary so the result has the normal single trailing newline rather than an extra blank line. A semicolon belonging to the wrapped statement must remain attached to that statement exactly once. The behavior must work independently for multiple direct top-level statements in one input, must be idempotent after fixing, and must not unwrap parentheses that are part of a nested subquery expression. Fixed output must remain parseable and must no longer report L053.
