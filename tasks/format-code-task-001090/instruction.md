Repository tree and diff views expose submodules through the template helper `InferSubmoduleURL`, but its current best-effort conversion is inconsistent: some Git URL forms lose repository structure, relative URLs are left as literal paths, and malformed inputs can be rewritten into misleading links. Make this public helper produce stable web links while preserving its existing fallback role.

For an `http` or `https` submodule URL, remove one trailing slash and a trailing `.git` repository suffix, then append `/commit/<commit>` when the submodule has a non-empty commit. Preserve the URL's path hierarchy, query, and fragment, placing the commit path before query and fragment. SSH URLs, including credentials and an explicit port, must become an `http` URL using only the hostname and repository path; SCP-style `user@host:path` URLs follow the same conversion.

Resolve relative submodule URLs against the current repository URL treated as its directory, including `./`, `../`, and nested relative paths, and normalize dot segments before adding the commit link. The base URL may or may not end in `/`. When the commit is empty, return the normalized repository URL without a trailing `/commit/`. Unsupported schemes, empty URLs, and URLs that fail parsing must be returned unchanged, including their original spelling. Keep the helper's existing signature and remain compatible with the template call site.
