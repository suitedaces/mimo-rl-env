I want a stateful Go storage cache wrapper in package storage, constructed with NewCachedDiskStorageManager(*DiskStorageManager, int) *CachedDiskStorageManager. The returned object should satisfy the storage.Manager-style lifecycle with Name() string, Root(int) uint64, SetRoot(int, uint64), Insert(interface{}) (uint64, error), Update(uint64, interface{}) error, Free(uint64) error, Fetch(uint64, interface{}) error, FetchCached(uint64) (interface{}, error), Rollback() error, Flush() error, and Close() error.

Name, Root, SetRoot, Flush, and Close should behave like the wrapped DiskStorageManager operations, so setting root 5 to 20 through the cached wrapper makes both the wrapper and the wrapped disk manager report root 5 as 20. Insert should store the object in the wrapped disk manager, return its logical location, and make the inserted object immediately available through FetchCached at that location. Fetch should read from the wrapped disk manager into the supplied destination object and keep that fetched value available for future FetchCached calls. Update should write the new value to the wrapped disk manager and make FetchCached for that location return the updated object; for example after inserting "test66" and updating that location to "test77", FetchCached should return "test77" and a direct disk fetch should also read "test77". Free should free the wrapped disk location and remove the cached object, so future fetches for that location fail according to the wrapped disk manager and FetchCached no longer returns the old value.

FetchCached for a location that is not currently cached should return a *ManagerError whose Type is ErrNotInCache. The cache size limit passed to NewCachedDiskStorageManager should be enforced by evicting the least recently used cached object: with a max size of 3, fetching locations for "test1", "test2", and "test3" should cache all three, then fetching a fourth location for "test4" should evict "test1" while leaving the newer entries accessible. Accessing an existing cached entry through Fetch should make it the most recently used entry for later eviction decisions. Rollback should delegate to the wrapped disk manager when transactions are enabled and clear all cached entries; after inserting "test1" and rolling back on a transactional disk manager, FetchCached for that location should miss and Fetch should report the rolled-back disk location as not found. If transactions are disabled on the wrapped disk manager, Rollback should be a no-op that returns nil.
