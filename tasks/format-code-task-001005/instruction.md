Make `ghstack checkout` produce a reusable local checkout instead of leaving users on the remote `orig` commit in detached-HEAD state. A user should be able to run checkout again later to synchronize that same review branch, while local commits remain protected unless replacement is explicitly requested.

Extend the public `ghstack.checkout.main` callable with optional `branch: Optional[str] = None`, `force: bool = False`, and `detach: bool = False` keyword arguments, retaining its existing arguments. The GitHub PR lookup must yield a conventional `gh/<username>/<number>/head` ref; reject any other head-ref shape with `RuntimeError` and do not switch HEAD or create a checkout branch. For a valid PR, fetch the selected remote and use the corresponding `gh/<username>/<number>/orig` ref so the checkout contains the clean commits for the whole stack through that PR.

In normal branch mode, require a completely clean index and worktree before changing checkout state: staged changes, unstaged tracked changes, and untracked files must each cause `RuntimeError`, with the current branch, HEAD, files, and prospective checkout branch left intact. If `branch` is omitted, derive the local name `ghstack/<owner>/<repo>/<PR number>` from the PR URL; otherwise use the supplied name. A newly created local branch must start at and track `<remote_name>/gh/<username>/<number>/orig`. Honor non-default remote names for fetching, the target ref, and tracking configuration.

Repeated checkout must distinguish all ancestry states after fetching. If the local branch equals the remote `orig`, simply reuse it without changing its commit or worktree. If it is behind, fast-forward it to the fetched `orig`. If it is ahead, check it out and preserve its local commits. If local and remote have diverged, raise `RuntimeError` without discarding the local tip or its files. With `force=True`, that diverged branch is instead replaced by the fetched `orig` and checked out.

Keep an explicit compatibility mode: `detach=True` checks out the fetched remote `orig` commit directly, leaves HEAD detached, and does not create the derived local branch. `detach=True` and an explicit `branch` are mutually exclusive and must raise `RuntimeError` without changing checkout state. Expose these modes on the `ghstack checkout` command as `--branch BRANCH`, `--force`, and `--detach`; the command must forward the selected values to the checkout workflow, using `None`, `False`, and `False` respectively when those flags are omitted.
