I want `tf_quant_finance.datetime.BusinessDaySchedule(start_date: DateTensor, end_date: DateTensor, holiday_calendar: HolidayCalendar, backward: bool = False).dates() -> DateTensor` for generating a DateTensor that contains every business day between the start and end dates, inclusive, according to the supplied holiday calendar.

For a non-batched example, with a Saturday/Sunday weekend calendar and no extra holidays, `start_date = [(2020, 3, 19)]` and `end_date = [(2020, 3, 25)]` should return `[[(2020, 3, 19), (2020, 3, 20), (2020, 3, 23), (2020, 3, 24), (2020, 3, 25)]]`. If the requested range begins on a non-business day, the start should first roll forward to the next business day; if it ends on a non-business day, the end should first roll backward to the previous business day.

For batched inputs, the returned DateTensor should have one extra trailing schedule dimension and all rows should be padded to the longest generated schedule. With `backward=False`, shorter schedules should be padded at the end with their adjusted end date. With `backward=True`, shorter schedules should be padded at the beginning with their adjusted start date while preserving monotonic increasing dates.

For example, with a Saturday/Sunday weekend calendar and a holiday on 2020-03-20, a schedule from 2020-03-19 to 2020-03-25 should return `[(2020, 3, 19), (2020, 3, 23), (2020, 3, 24), (2020, 3, 25)]`. Calling the same schedule twice with the same inputs should produce the same ordinals and should not mutate the input DateTensors or the holiday calendar. If the adjusted end date is earlier than the adjusted start date, `dates()` should fail with TensorFlow's invalid-argument assertion for `End date must be >= Start date.`
