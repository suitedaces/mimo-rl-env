I want `python train.py` and `python test.py` to support `--dataset_mode unaligned` for unsupervised image-to-image translation datasets. When I pass `--dataroot DATASET --phase train`, the loader should read domain A images from `DATASET/trainA` and domain B images from `DATASET/trainB`; for `--phase test`, it should read `DATASET/testA` and `DATASET/testB`, falling back to `DATASET/valA` and `DATASET/valB` when `testA` is absent and `valA` exists.

Each batch should contain one transformed RGB image from domain A, one transformed RGB image from domain B, and the source path for each image. With `--serial_batches`, item index `i` should pair `A[i % len(A)]` with `B[i % len(B)]`; without `--serial_batches`, the A side should still follow the requested index while the B side is sampled randomly from the B folder. The dataset length should be the larger of the A and B folder sizes so the shorter side cycles by modulo indexing.

The unaligned mode should honor the existing preprocessing options for both domains, including resize/crop/flip/tensor normalization. During training epochs after `--n_epochs`, it should switch the transform load size to `--crop_size` so finetuning no longer uses the larger resize-crop augmentation. If the selected A or B folder is missing, dataset creation should fail instead of silently producing empty batches.
