I want to use PYBOSSA's Python importer API as a stateful object: `imp = Importer()`, optionally call `imp.register_flickr_importer(flickr_params)`, `imp.register_dropbox_importer()`, `imp.register_twitter_importer(twitter_params)`, or `imp.register_youtube_importer(youtube_params)`, then call `imp.count_tasks_to_import(**form_data)` or `imp.create_tasks(task_repo, project_id, **form_data)`. A new `Importer()` should support `type` values `csv`, `gdocs`, `epicollect`, `s3`, `localCSV`, and `iiif` by default, and each registration method should make its corresponding source name available on that importer instance.

`get_all_importer_names()` should return the currently available source names. `get_autoimporter_names()` should return the currently available source names except `dropbox` and `s3`, so a fresh importer reports `csv`, `gdocs`, `epicollect`, `localCSV`, and `iiif`, while a registered Flickr or Twitter importer appears in the autoimporter list and a registered Dropbox importer does not.

`count_tasks_to_import(**form_data)` should select the source importer named by `form_data['type']`, construct it from the remaining form data plus any credentials registered for that source, and return that source importer's task count without saving tasks. `create_tasks(task_repo, project_id, **form_data)` should select the same source importer, iterate its task dictionaries, create a task for the requested project, copy each yielded key onto that task, and save it only when `task_repo.get_task_by(project_id=project_id, info=task.info)` finds no existing task.

If `create_tasks` saves one new item whose `info` is `{'question': 'question'}`, it should return an `ImportReport` with `message == '1 new task was imported successfully'`, `total == 1`, and `metadata` equal to the selected source importer's import metadata. If it saves two new items, the message should be `2 new tasks were imported successfully` and `total == 2`. If every yielded item is already present for the project, or the source yields no items, it should save nothing and return an `ImportReport` with `message == 'It looks like there were no new records to import'`, `total == 0`, and `metadata is None`.

`ImportReport(message, metadata, total)` should expose `.message`, `.metadata`, and `.total` properties so callers can show the import status, inspect source metadata from the run, and know how many new tasks were created.
