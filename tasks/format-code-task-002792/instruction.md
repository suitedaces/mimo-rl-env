I want public parser entry functions `parse_src_str(str, params)`, `parse_src_file(filename, params)`, and `parse_src_port(port, params)` for one-shot JavaScript source parsing. `parse_src_str("var x = 1;", params)` should behave the same as parsing a `String_input_port` over that source, returning the normalized `Program` AST for the source string. `parse_src_file("input.js", params)` should read that filename through the existing file input port path and return the normalized `Program` AST for the file contents. `parse_src_port(port, params)` should require `params` to be a `CompParams`, construct the scanner and parser using `params.parserWarnings`, parse the port, normalize the AST using `params.debugTrace`, and return that normalized tree. If `params.printAST` is true, the normalized AST should also be printed before the function returns. Passing an undefined filename to `parse_src_file`, an undefined source string to `parse_src_str`, or a non-`CompParams` params object to `parse_src_port` should raise the normal assertion error for that invalid call.
