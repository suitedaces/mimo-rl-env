I need a `pyte.DiffScreen(columns, lines)` stateful screen class for incremental terminal redraws. It should behave like a normal terminal screen while also exposing a mutable `dirty` set of zero-based row numbers that tells callers which rows need to be repainted; callers are responsible for clearing that set after they consume it.

For example, `screen = pyte.DiffScreen(5, 3)` should start with `screen.dirty == {0, 1, 2}` because the initial blank screen needs a full draw. After `screen.dirty.clear(); screen.draw(u"A")`, `screen.display[0]` should start with `"A"` and `screen.dirty` should be `{0}`. Each instance should own an independent dirty set, so clearing or drawing on one `DiffScreen` must not change another instance.

The public methods `reset()`, `resize(...)`, and `alignment_display()` should mark every line dirty. `draw(...)`, `insert_characters(...)`, `delete_characters(...)`, `erase_characters(...)`, and `erase_in_line(...)` should mark the current cursor row dirty. `insert_lines(...)` and `delete_lines(...)` should mark every row from the current cursor row through the bottom of the screen. `index()` should mark all rows dirty when it scrolls at the bottom margin, and `reverse_index()` should mark all rows dirty when it scrolls at the top margin. `erase_in_display(0)` should dirty the cursor row through the bottom, `erase_in_display(1)` should dirty the top through the cursor row, and `erase_in_display(2)` should dirty the whole screen. When private reverse-screen mode is toggled through `set_mode(...)` or `reset_mode(...)`, every row should be marked dirty as well.
