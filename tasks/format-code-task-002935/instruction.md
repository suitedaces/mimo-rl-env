I want a pure `alt.to_values(data)` helper that converts supported Python data inputs into a Vega-Lite inline data dictionary of the form `{"values": ...}`. For `pd.DataFrame({"x": [1, 2], "y": ["a", "b"]})`, it should return `{"values": [{"x": 1, "y": "a"}, {"x": 2, "y": "b"}]}`. For an input dictionary that already has a `values` key, such as `{"values": [{"x": 1}]}`, it should return that values data dictionary unchanged.

It should also accept objects exposing `__geo_interface__` and return sanitized GeoJSON-compatible values, and it should accept Narwhals dataframe inputs by returning their named rows after Altair-compatible sanitization. If I pass a dictionary without a `values` key, it should raise `KeyError`. If I pass an unsupported object like `0`, it should raise `TypeError`. Calling it repeatedly with the same input should produce the same result, should not mutate the input data, and should not write files, use the network, or change global transformer state.
