I want `python algos/main.py` to support a TRPO training mode selected with `--algo-name TRPO`, and to use TRPO by default when `--algo-name` is omitted. For example, `python algos/main.py --env-name CartPole-v0 --algo-name TRPO --max-iter-num 1` should build the policy/value networks, collect a trajectory batch, estimate reward advantages and returns, and run a TRPO batch update instead of the constrained CPO update.

In TRPO mode, argument parsing should provide the trust-region settings `--max-kl` and `--damping` with defaults of `1e-2`, while the existing `--l2-reg` value regularizes value-function fitting. The batch update should fit the value network to the computed returns with L-BFGS, compute the policy surrogate from old and current action log probabilities and the advantages, solve the natural-gradient direction with conjugate gradients, scale the step to respect the KL limit, and use backtracking line search so only an adequately improving policy step is accepted. After each TRPO update, the policy and value networks should be mutated in place, the value loss and policy loss should be passed back to the training loop, and the cost loss used for logging should be `0` because TRPO has no constraint-cost objective.
