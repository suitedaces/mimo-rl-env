Each row of `P` should sum to one, probabilities should be nonnegative up to numerical tolerance, repeated calls with the same arguments should return equal arrays, and the function should not mutate any caller-owned inputs or perform filesystem, network, or global-state side effects.

If `n` is not an integer, the function should emit a `UserWarning` explaining that the public API is `tauchen(n, rho, sigma, mu=0., n_std=3)` and then fail with the normal type error produced by trying to use the non-integer state count.
