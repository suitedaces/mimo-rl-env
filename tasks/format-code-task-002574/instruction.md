I want the stateful fuzzynote client created with `NewClientBase(db *DBListRepo, maxWidth int, maxHeight int, useClientSearch bool)` to support exporting the current visible match set through `HandleInteraction(ev InteractionEvent, search [][]rune, showHidden bool, bypassRefresh bool, limit int)`. When `ev.T` is `KeyExport`, the client should ask the repository for the items matching the provided `search` groups and `showHidden` flag, then write those matched list lines to a new plain text file in the process's current working directory.

The exported file name should follow `export_<timestamp>.txt`, where the timestamp is generated at export time. Each matched item should be written as its stored line text followed by a newline, in the same order returned by matching, and item notes should not be included. For example, after a session creates items `alpha`, `beta`, and `alphabet`, calling `HandleInteraction` with `KeyExport`, search group `[][]rune{[]rune("alpha")}`, and `showHidden=false` should create one `export_*.txt` file containing `alpha\n` and `alphabet\n`, but not `beta\n`. If a matched item is hidden, it should appear in the export only when the call passes `showHidden=true`.

The terminal adapter should map the `Ctrl-^` keypress to this export interaction, so a user running the terminal app can search, press `Ctrl-^`, and get the same `export_*.txt` file without changing the cursor or list contents.
