CKAN extension test configurations commonly inherit the core test configuration with `[app:main] use = config:<path>`. `CKANConfigLoader` currently handles one parent, but an extension configuration that inherits an environment-specific overlay (which itself inherits the core file) silently stops after that first hop. Make configuration inheritance transitive and safe without changing the established one-file and two-file behavior.

Starting from the file passed to `CKANConfigLoader`, follow every `[app:main] use = config:<path>` reference until a non-`config:` `use` value is reached. Relative references are resolved against the directory of the file that declares them, including at intermediate levels; absolute references remain valid. Merge ordinary `[app:main]` options so that the most specific (initial/child) file wins conflicts, while options found only in any ancestor remain available. Interpolation is scoped to the declaring file: every `%(here)s` used by either an application option or a `DEFAULT` option expands to that file's directory before layers are combined.

Preserve CKAN's existing `DEFAULT` compatibility semantics across the full chain. Defaults from every layer must appear both in the top-level result and in `global_conf`; when the same default is declared at multiple levels, the farthest ancestor wins. In the returned metadata, `__file__` in both locations continues to identify the initial file, while `global_conf['here']` identifies the directory of the terminal ancestor. Existing direct/single-level loading and the current two-file precedence and interpolation results must remain unchanged.

Invalid inheritance must fail deterministically with `CkanConfigurationException`. A missing referenced file must produce a message containing `not found` plus the absolute normalized paths of both the referring file and missing target. An empty `config:` target must produce a message containing `config`, `empty`, and the initial file path. Direct self-inheritance must produce a message containing `circular` and the file path. An indirect cycle must likewise contain `circular` and the absolute normalized path of every file in the cycle, so operators can diagnose the complete chain.
