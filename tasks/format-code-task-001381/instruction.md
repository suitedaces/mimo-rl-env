I want OpenGL windows to expose the typed text collected during the current frame through `func (w *Window) Typed() string`. In a session created with `win, err := opengl.NewWindow(cfg)`, if the user types `a` and then `b` before the next input update, `win.Typed()` should return `"ab"` for that frame. If the user types a Unicode character such as `é`, the returned string should include that character as UTF-8 text, not a key name or physical key code. The typed buffer should be frame-based: after `win.Update()`, `win.UpdateInput()`, or `win.UpdateInputWait(...)` advances input with no new character events, `win.Typed()` should return an empty string. Keyboard button state is separate from typed text, so pressing non-text keys should not add text to `Typed()`.
