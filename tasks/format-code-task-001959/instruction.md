I want Moment durations created with `moment.duration(input)` to serialize themselves as ISO 8601 duration strings through `duration.toISOString() -> string`. For `moment.duration(0).toISOString()` the result should be `P0D`, and for `moment.duration({ days: 1, hours: 2, minutes: 3, seconds: 4, milliseconds: 5 }).toISOString()` the result should be `P1DT2H3M4.005S`. Month buckets should serialize separately from day and time buckets: `moment.duration({ months: 14 }).toISOString()` should return `P1Y2M`.

The method should preserve the sign rules for each internal bucket when a duration contains mixed positive and negative components, rather than flattening everything into one unit. Invalid durations should return the active locale's invalid-date text, for example `moment.duration.invalid().toISOString()` should return `Invalid date` in the default English locale. I also need `duration.toString()` and `duration.toJSON()` to return the same string as `duration.toISOString()`, so implicit string conversion and JSON serialization expose the ISO duration value. The compatibility spelling `duration.toIsoString()` should call the same serializer and emit the standard deprecation warning for that spelling.
