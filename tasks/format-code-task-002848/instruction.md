I need a `DownloadModel` class for preparing model assets before a render is queued. It should be used as `dm = DownloadModel(modelFile: str, downloadModelFile: str, modelPath: str = MODELS_PATH)` followed by `dm.downloadModel() -> bool`.

Constructing it should remember the target model filename, the release asset filename, and the model directory, and it should ensure the model directory exists. When `downloadModel()` is called and `modelPath/modelFile` already exists as either a file or a directory, it should return `True` without requiring internet access or downloading anything. For example, `DownloadModel("rife-v4.6", "rife-v4.6.tar.gz", "/tmp/models").downloadModel()` should return `True` if `/tmp/models/rife-v4.6` already exists.

If the model is missing and the machine has no network connection, `downloadModel()` should return `False` so the caller can show a user-facing failure and avoid adding the render job. If the model is missing and the network is available, it should download from `https://github.com/TNTwise/real-video-enhancer-models/releases/download/models/<downloadModelFile>` into `modelPath/downloadModelFile`, using a user-visible progress dialog titled `Downloading: <downloadModelFile>`, then print `Done` and return `True`. If `downloadModelFile` contains `tar.gz`, it should also print `Extracting File` and extract the downloaded archive after the download completes; plain model files such as `GMFSS.pkl` should be downloaded without archive extraction.
