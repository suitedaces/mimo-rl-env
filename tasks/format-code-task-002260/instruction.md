I need the TypeScript Admin API client to support deleting Ghost resources by id after I create a client with `new TSGhostAdminAPI(url, key, version, options?)`. The delete method should be available as `api.posts.delete(id: string)`, `api.pages.delete(id: string)`, `api.members.delete(id: string)`, `api.tags.delete(id: string)`, and `api.webhooks.delete(id: string)`, and custom resource clients built with `APIComposer` should expose the same `delete(id: string)` method.

Calling `delete` with a non-empty id should send a Ghost Admin API DELETE request for that resource identity and return a promise. When Ghost responds with HTTP 204, the promise should resolve to `{ success: true }`. When Ghost responds with an error JSON payload such as `{ errors: [{ type: "NotFoundError", message: "Resource not found", context: "Could not find Post" }] }` and a status like 404, the method should resolve to `{ success: false, errors: [{ type: "NotFoundError", message: "Resource not found", context: "Could not find Post" }], status: 404 }`. If the underlying fetch throws, it should resolve to a failed result with `status: 0` and a single error whose `type` is `"FetchError"`. Calling `delete("")` should reject before making the request because the id is invalid.
