I want a command-line way to update a Zim notebook's page/link/tag index without opening the GUI. The invocation should be `zim --index NOTEBOOK`, where `NOTEBOOK` is a notebook name, path, or URI accepted by the normal notebook resolver. Running it should open that notebook with index freshness handled by the command itself, check the existing index for stale files, update whatever needs updating, and exit successfully when the index is current.

I also need `zim --index --flush NOTEBOOK` and `zim --index -f NOTEBOOK` to discard the existing index first and rebuild it completely. With verbose output enabled, the command should make indexer debug messages visible as info-level terminal output and should report that it is checking the notebook index and that the index is up to date. The command must require exactly one notebook argument and should use the standard command-line error path with a non-zero exit when the notebook argument is missing or cannot be resolved.

`zim --help` should advertise this feature with a usage line for `zim --index [OPTIONS] NOTEBOOK`, a general option entry saying `--index` builds an index for a notebook, and an Index Options section documenting `-f, --flush` as flushing the index before rebuilding.
