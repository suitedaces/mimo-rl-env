Harden authorization-rule validation and rights translation for the Event Hub and Service Bus resources. These resources expose listen, send, and manage booleans that are converted to Azure access-rights lists and reconstructed from API responses. Configuration must be rejected when no right is enabled (including when all three values are omitted or explicitly false). A manage right is valid only when both listen and send are also enabled; listen-only and send-only rules remain valid. Validation must report a normal error for every invalid combination, including partially specified input, rather than panicking or silently accepting it. The conversion in either service must emit each enabled right at most once in the stable Listen, Send, Manage order, and flattening must set the corresponding booleans from returned known rights. Keep the behavior consistent between Event Hub and all Service Bus authorization-rule resources, and do not change unrelated schema fields or computed credentials.
