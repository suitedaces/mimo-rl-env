I want the backend CLI to support `--list_backends` as a standalone availability check, invoked as `python backend/rve-backend.py --list_backends`, without requiring an input video or output path. It should inspect the installed inference runtimes and print a plain-text report to stdout, then exit successfully.

The report should start with `RVE Backend Version: <version>` and end with `Available Backends: [...]`. If PyTorch is importable, it should include `PyTorch Version: <version>`, append `pytorch (<device>)` to the available backend list, print each detected PyTorch device as `PyTorch GPU <index>: <name>`, and include whether half precision is supported. If NCNN is importable, it should append `ncnn`, print `NCNN Version: 20220729`, and print each NCNN device as `NCNN GPU <index>: <name>`. If TensorRT is importable and half precision works, it should append `tensorrt` and print `TensorRT Version: <version>`; if TensorRT is present but the GPU cannot support it, the report should include `ERROR: Cannot use tensorrt backend, as it is not supported on your current GPU` instead of listing TensorRT as available.

For an environment with no supported runtimes, the command should still exit 0 and print `Half precision support: False` followed by `Available Backends: []`. The command should write the availability report to stdout rather than stderr, and it should not start video probing or rendering when `--list_backends` is used.
