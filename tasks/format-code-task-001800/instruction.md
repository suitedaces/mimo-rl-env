I want the `linuxkit` CLI to provide a cache listing command at `linuxkit [--cache DIR] cache ls`. When I run it successfully, it should read the LinuxKit OCI cache from the selected cache directory, exit with status 0, and emit a table whose header contains `image name` and `root manifest hash`, followed by one line for each cached image reference and its root manifest digest. The image name column should be padded consistently so hashes line up in a second column, including long canonical names such as `docker.io/library/nginx:latest`.

The command should require no positional arguments and should appear in `linuxkit cache --help` as `ls` with help text that says it lists images in the LinuxKit cache. If the cache cannot be opened or its image names cannot be read, `linuxkit cache ls` should exit non-zero and print an error containing `error reading image names:` with the underlying failure. The global `--cache DIR` flag must control which cache directory is listed.
