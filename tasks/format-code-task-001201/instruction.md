I want a `fonttools feaLib` command that compiles an Adobe OpenType feature file into an existing font from the shell. The command should be invoked as `fonttools feaLib FEATURES INPUT_FONT`, with optional `-o/--output OUTPUT_FONT`, `-t/--tables TABLE_TAG ...`, `-d/--debug`, repeated `-v/--verbose`, and `--traceback` flags.

On a successful run, it should load `INPUT_FONT`, apply the feature source from `FEATURES`, and save the resulting font to `OUTPUT_FONT`; if `--output` is omitted, it should use the standard fontTools output filename derived from the input font. `--tables` should only accept supported feature-build table tags and pass those selected tags through so only those tables are built. `--debug` should request source-level lookup debugging information in the output font. Repeating `-v` should increase logging verbosity, so `-v` enables informational logging and `-vv` enables debug logging.

For invalid feature source reported by the feature compiler, the command should log the compilation error and exit with status 1. If `--traceback` is also supplied for that same compiler error, it should let the exception traceback propagate instead of converting it to the short logged error. `fonttools feaLib --help` should print usage for the command and its flags to stdout and exit with status 0.
