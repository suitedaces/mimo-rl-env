`Range` is the common rectangular storage used by the workbook readers, but its public coordinate APIs currently disagree at important boundaries: sparse construction assumes a particular input order, incremental updates cannot move the origin, relative lookup can wrap into another row, and selecting from an empty range can panic. Make these APIs behave as one consistent two-dimensional abstraction while keeping their existing public signatures and coordinate conventions (absolute sheet coordinates for `set_value`, `get_value`, and `range` bounds; relative coordinates for `get`, `cells`, and `used_cells`).

`Range::from_sparse` must accept cells in arbitrary order. Its bounds are the minimum and maximum row and column present, holes contain `T::default()`, and when the input repeats a coordinate the last cell in input order wins. Empty input must still produce an empty range.

`Range::set_value` must work on an empty range, turning it into a one-cell range at the requested absolute position. On a non-empty range it must accept positions on any side of the current bounds: upward and leftward growth are required independently, and the existing downward and rightward growth must remain supported. After any growth, the bounds are the smallest rectangle containing the old range and the new position, old values retain their absolute coordinates, the requested value is stored, and newly introduced holes are default-valued. Rows must remain rectangular.

Relative `Range::get((row, column))` must return `Some` only when both coordinates are within the range; an oversized column must not wrap into the next row, and any out-of-bounds coordinate returns `None` without arithmetic overflow. Calling `range(start, end)` on an empty source must not panic: it returns the requested non-empty rectangle filled with defaults, just as a selection with no overlapping source cells should.

Finally, resizing must preserve iterator semantics. `cells()` continues to visit every cell in relative row-major order, and `used_cells()` continues to visit only non-default cells in that same order, reporting coordinates relative to the range's possibly changed origin.
