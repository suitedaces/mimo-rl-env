I want github-automated-repos to expose a React hook named `useGitHubAutomatedRepos` from both package entry points. From `github-automated-repos`, the hook signature should be `useGitHubAutomatedRepos(gitHubUsername: string, keyWord: string): { data: IGitHubRepos[] | undefined; isLoading: boolean; error: Error | null }`. From `github-automated-repos/react-query`, the hook signature should be `useGitHubAutomatedRepos(gitHubUsername: string, keyWord: string, options?: Omit<UseQueryOptions<IGitHubRepos[], Error, IGitHubRepos[], [string, string, string]>, 'queryKey' | 'queryFn'>): UseQueryResult<IGitHubRepos[], Error>`. Both entry points should also export an `IGitHubRepos` type with `name`, `topics`, `html_url`, `description`, `id`, `homepage`, and `banner` fields.

For the root hook, when I call `useGitHubAutomatedRepos('octocat', 'portfolio')` in a component and the repository feed resolves to `[{ id: 1, name: 'portfolio-site', topics: ['portfolio', 'react'], html_url: 'https://github.com/octocat/portfolio-site', description: 'Portfolio', homepage: 'https://octocat.example', banner: ['https://raw.example/banner.png'] }]`, the hook should first expose `{ data: undefined, isLoading: false, error: null }`, then set `isLoading` to true while loading, and finally expose that array in `data` with `isLoading: false` and `error: null`. If the same hook is called as `useGitHubAutomatedRepos('', 'portfolio')` or `useGitHubAutomatedRepos('octocat', '')`, it should not start the fetch and should keep `data` undefined, `isLoading` false, and `error` null. If the feed rejects with an `Error`, the hook should finish with `isLoading: false` and that `Error` in `error`; if it rejects with a non-Error value, expose `new Error('Unknown error occurred')` instead.

For the React Query import, `useGitHubAutomatedRepos('octocat', 'portfolio', { staleTime: 600000, refetchInterval: false, refetchOnWindowFocus: false })` should delegate to TanStack Query with query key `['githubRepos', 'octocat', 'portfolio']`, call the same portfolio repository feed using those two strings, and pass through caller options other than `queryKey` and `queryFn`. For example, a `QueryClient` should cache the `('octocat', 'portfolio')` result separately from `('octocat', 'attached')`, and setting `enabled: false` should let React Query prevent the request. Both hook surfaces should return repository arrays with the fields from `IGitHubRepos` unchanged, and repeated calls with the same arguments should produce the same observable hook result when the feed returns the same data.
