I want SimpleTalk worlds to be saveable as self-contained HTML snapshots from the live browser session. The browser `System` object should expose `getFullHTMLString(): string`, which clones the current document, removes the live `<st-world>` and `<st-navigator>` elements from that clone, and returns the cloned document's full outer HTML so the page can later load from its embedded `#serialization` JSON.

I also want the SimpleTalk/System command `saveHTML(fileName?)` to export the current world. When invoked, it should use the supplied `fileName` argument when present, otherwise read the current world's `name` property, serialize the current world into the `#serialization` script element, build the snapshot HTML with `getFullHTMLString()`, and trigger a browser download named `<fileName>.html` using a hidden anchor. If hand detection is running during the save, the command should stop it before serialization/download and start it again afterward. The part context menu should include a `Save Snapshot...` item that sends the `saveHTML` command from the world so users can trigger the same download without writing a script.
