I want the `nodefront minify` CLI to optimize image assets as part of the minify command. `nodefront minify --images` and `nodefront minify -i` should select JPEG and PNG files, including `.jpg`, `.jpeg`, and `.png` targets, and run the appropriate image optimizer for each matched file. A plain target should also work with an explicit image type, for example `nodefront minify -p images/photo.jpg -t jpg` and `nodefront minify -p images/icon.png -t png`.

On a successful run, the command should write the optimized image to the output path chosen by the minify command and print a line like `Optimized images/photo.jpg to images/photo.min.jpg.` or `Optimized images/icon.png to images/icon.min.png.` to stdout. Successful image optimization should exit with code 0. If the image optimizer process reports an error, the command should fail with a non-zero exit code and should not print the success message for that file. `nodefront minify --help` should advertise `-i, --images` as the shortcut for optimizing JPEG/PNG files, and the `--type` help text should list `jpg`, `jpeg`, and `png` as supported forced types.
