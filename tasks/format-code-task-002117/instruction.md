I want MMSelfSup to provide an `ImageList` dataset that I can import with `from mmselfsup.datasets import ImageList` and also reference in configs as `type='ImageList'`. The constructor should be `ImageList(ann_file: str, metainfo: Optional[dict] = None, data_root: str = '', data_prefix: Union[str, dict] = '', **kwargs) -> None`, and it should accept the normal CustomDataset/BaseDataset keyword arguments such as a pipeline.

The dataset needs to read an annotation text file where each nonempty line starts with a relative image path. If a line has two columns, such as `folder_1/xxx.png 0`, the second column is the class label; if the file is unlabeled and a line has only `folder_1/xxx.png`, that sample's label should be `-1`. For a two-line unlabeled file containing `folder_1/xxx.png` and `folder_2/123.png`, `len(dataset)` should be 2 and the first record should resolve `img_path` by joining the image prefix with `folder_1/xxx.png`, keep `img_info['filename'] == 'folder_1/xxx.png'`, and expose `gt_label` as a NumPy int64 scalar array equal to `-1`. For a labeled line `folder_1/xxy.png 3`, the corresponding record should expose `gt_label` as a NumPy int64 scalar array equal to `3`.

The public `load_data_list(self) -> List[dict]` method should return the parsed list of records with `img_prefix`, `img_path`, `img_info`, and `gt_label` for every sample. Constructing the dataset with an empty `ann_file` should fail with `AssertionError` instead of silently creating an empty dataset. The dataset should use the common image extensions `.jpg`, `.jpeg`, `.png`, `.ppm`, `.bmp`, `.pgm`, and `.tif` when delegating file handling to the underlying dataset base class.
