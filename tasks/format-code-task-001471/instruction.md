I want a command-line converter for preparing GSM8K data for MathRuler. I should be able to run `python scripts/gsm8k_to_math.py <data_folder>`, where `<data_folder>` contains `train.jsonl` and `test.jsonl` from the original GSM8K release, and the command should create `data/gsm8k_splits/` if needed and write normalized `train.jsonl` and `test.jsonl` files there.

Each input line is a JSON object with `question` and `answer`. The converter should parse the final numeric answer from the GSM8K marker format `#### <number>`, remove that marker from the worked solution, strip commas out of the extracted answer, and write each output line as JSON with exactly `problem`, `solution`, and `answer`. For example, an input record with `question: "What is 1,000 plus 20?"` and `answer: "Add them. #### 1,020"` should produce `problem: "What is 1,000 plus 20?"`, `answer: "1020"`, and a solution ending with `Add them. The answer is $\boxed{1020}$.`.

If the worked solution does not already end with a period before the final marker, the converter should add one before appending the boxed-answer sentence. For example, `answer: "Compute 2+2 #### 4"` should produce a solution ending with `Compute 2+2. The answer is $\boxed{4}$.`. A successful conversion should finish with exit code 0 and should not print the converted records to stdout.

If any input answer does not contain a `#### <number>` marker, such as `"No final marker here"`, the command should fail instead of silently writing a bad record. The failure should be a non-zero CLI exit caused by a `ValueError` whose message includes `Cannot extract answer in No final marker here.`.
