I want a public `locust.stats.get_readable_percentiles(percentile_list: list[float]) -> list[str]` helper that formats percentile fractions as human-readable percentage labels for reports. It should return a new list and leave the input list unchanged, with no filesystem, network, or global-state side effects.

For `get_readable_percentiles([])`, it should return `[]`. For `get_readable_percentiles([0.5, 0.66, 0.75, 0.8, 0.95, 1.0])`, it should return `["50%", "66%", "75%", "80%", "95%", "100%"]`. For high-precision fractions like `get_readable_percentiles([0.999, 0.9999, 0.666666])`, it should return `["99.9%", "99.99%", "66.6666%"]`, using integer labels when the percentage is a whole number and otherwise rounding the percentage value to at most 6 decimal places before adding `%`. Calling it multiple times with the same input should produce equal results. If an item is not numeric, for example `get_readable_percentiles([None])`, the call should fail with `TypeError` rather than silently returning an invalid label.
