I want a pure `pairAnchorsAndFootnotes(timeline: Array) -> Object` utility that turns a chronological stream of inline footnote events into a lookup table keyed by marker code and anchor index. The input timeline contains events with `type: "anchor"` or `type: "footnote"`; anchor events include `markerCode` and `index`, and footnote events include `markerCode` and `content`.

For example, calling `pairAnchorsAndFootnotes([{type:"anchor", markerCode:"9312", index:0}, {type:"footnote", markerCode:"9312", content:"first note"}])` should return an object where `result["9312"][0] === "first note"`. If repeated markers appear, pairing should follow reading order: `[{type:"anchor", markerCode:"9312", index:0}, {type:"anchor", markerCode:"9312", index:1}, {type:"footnote", markerCode:"9312", content:"first"}, {type:"footnote", markerCode:"9312", content:"second"}]` should produce `result["9312"][0] === "first"` and `result["9312"][1] === "second"`.

If an anchor cannot be matched to a later footnote before the group changes or before the timeline ends, its lookup entry should be the configured not-found footnote placeholder. Footnote events with no queued matching anchor can be ignored. Passing a non-array input should return an empty object. The function must be deterministic, must not mutate the input timeline, and must not read or write the filesystem, network, DOM, or hidden global state beyond using the configured footnote constants.
