I want the `offboard_control` ROS node, when started with `rosrun offboard_control offboard_control`, to include a building-scan phase after collision avoidance is started and before the marker-centering phase begins. The node should log `Scanning building`, take the current local pose and current yaw as the scan origin, then visit five collision-avoidance endpoints in order: descend to `SAFETY_ALTITUDE_VIO`, move 2 meters to the right relative to yaw, climb to `SAFETY_ALTITUDE_GPS`, move 4 meters to the left relative to yaw, and descend again to `SAFETY_ALTITUDE_VIO`.

For each scan endpoint, the node should publish that endpoint to the trajectory planner endpoint topic and continue publishing the current local MAVROS setpoint while spinning at the controller ROS rate. A scan leg should finish once the vehicle has stayed within 0.5 meters of the endpoint for 2 seconds worth of control-loop ticks, or it should stop early as soon as a fresh WhyCon marker pose has been received within the last 0.5 seconds. If the scan loop reaches its attempt limit without satisfying those conditions, it should emit the warning text `2*MAX_ATTEMPTS reached while scanning building. Aborting.`
