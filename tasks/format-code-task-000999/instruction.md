Improve the public `dvc.utils.collections.apply_diff(src, dest)` utility used when DVC rewrites parsed pipeline and lockfile data. It should reconcile mappings and sequences to the source while respecting the destination object that callers pass in. For compatible mutable containers, update them in place so custom mapping/list subclasses and attached attributes survive; recursively synchronize compatible nested containers, preserve equal destination scalar objects, and add/remove or resize entries as needed. When a source value changes container kind (mapping versus sequence) or a nested destination is immutable/incompatible, replace that value with a source-shaped value through the returned result instead of raising or leaving stale data. The function must return the effective synchronized value for every root input, including immutable roots and incompatible root kinds, while leaving the source untouched. Keep existing values when they compare equal, but apply changed scalar values exactly.
