I want the TrueCrypt command line to support an informational version command. When I run `truecrypt --version`, it should print exactly `TrueCrypt 7.1a\n` to stdout, write no error message, perform no volume operation, and exit with status 0. The option should take precedence over other valid command flags in the same invocation, so `truecrypt --version --create` still only prints the version line and exits successfully. `truecrypt --help` should list `--version` under Commands with the description `Display program version.`
