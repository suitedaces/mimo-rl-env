I want the Evmos CLI transaction command group for the ERC20 module to support `erc20 convert-erc20 CONTRACT_ADDRESS AMOUNT [RECEIVER]`. Running this command should create and generate or broadcast a `MsgConvertERC20` transaction that converts ERC20 tokens from the signing account into Cosmos coins.

The command should accept exactly two or three positional arguments: the ERC20 contract address, the integer amount, and an optional Cosmos bech32 receiver. If the receiver is omitted, the Cosmos coins should be sent to the signing account's own Cosmos address; if it is provided, it should be parsed as the receiver address. The sender field in the transaction message should be the signing account converted to its Ethereum hex address.

Invalid input should fail before transaction generation: a non-hex or otherwise invalid contract address should return an error mentioning `invalid ERC20 contract address`, and an amount that cannot be parsed as a Cosmos integer should return an error mentioning `invalid amount <value>`. The command should include the standard Cosmos transaction flags so users can run it in generate-only, simulation, or broadcast modes, and it should delegate successful transaction generation or broadcast to the normal Cosmos SDK CLI transaction flow.
