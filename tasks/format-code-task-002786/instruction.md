I want the `f5-tts_finetune-cli` command to support a finetuning checkpoint staging mode. When I run `f5-tts_finetune-cli --exp_name F5TTS_v1_Base --dataset_name MyVoice --finetune`, the command should choose the default pretrained F5TTS v1 base checkpoint from Hugging Face, create `ckpts/MyVoice` if needed, copy that checkpoint into the directory with a `pretrained_` filename prefix, print `copy checkpoint for finetune` when the copy happens, and then continue into the normal training flow. The same `--finetune` behavior should choose the default `F5TTS_Base` checkpoint for `--exp_name F5TTS_Base` and the default `E2TTS_Base` checkpoint for `--exp_name E2TTS_Base`.

I also need to be able to provide my own seed checkpoint with `--pretrain /path/to/model.pt` together with `--finetune`; in that case the CLI should copy my local file instead of downloading a default. If the source filename does not already start with `pretrained_`, the copied checkpoint should be renamed with that prefix; if it already has the prefix, the name should be kept. If the destination file already exists, the command should not copy again and should not print the copy message. `f5-tts_finetune-cli --help` should list both `--finetune` and `--pretrain`, and passing a missing `--pretrain` path should fail with a non-zero exit instead of silently starting from scratch.
