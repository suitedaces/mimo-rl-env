I want `caire.Processor` values to provide `Resize(img *image.NRGBA) (image.Image, error)` for resizing an already-decoded in-memory image according to the processor's public target-size options. For example, with a 100x80 `*image.NRGBA` and `&caire.Processor{NewWidth: 60}`, calling `p.Resize(img)` should return an image whose bounds are 60x80 and a nil error. With a 100x80 image and `&caire.Processor{NewHeight: 40}`, it should return bounds 100x40; with `&caire.Processor{NewWidth: 60, NewHeight: 40}`, it should return bounds 60x40 by coordinating both axes in one resize request.

The method should support both shrinking and enlargement: if a 100x80 image is resized with `NewWidth: 120`, the returned image should have width 120 while preserving height 80, and if `NewHeight: 100` is requested the returned image should have height 100 while preserving width 100. When `Percentage` is true, `NewWidth` and `NewHeight` are percentages instead of pixels: a 100x80 image with `&caire.Processor{NewWidth: 50, NewHeight: 50, Percentage: true}` should return bounds 50x40. Percentage mode is only for reducing images, so `&caire.Processor{NewWidth: 150, Percentage: true}` on a 100-pixel-wide image should return a non-nil error with the message `cannot use the percentage flag for image enlargement`.

When `Square` is true, both `NewWidth` and `NewHeight` must be provided, and the result should be square using the smaller requested side as the effective target. For a 120x80 image and `&caire.Processor{NewWidth: 70, NewHeight: 50, Square: true}`, `Resize` should return an image with bounds 50x50. If `Square` is true but either target dimension is missing, such as `&caire.Processor{NewWidth: 50, Square: true}`, `Resize` should return a non-nil error with the message `please provide a new WIDTH and HEIGHT when using the square option`. Vertical resizing should work through the same API as horizontal resizing, including when masks are attached through `Mask` or `RMask`, so callers do not need a separate rotate-orientation method to resize height.
