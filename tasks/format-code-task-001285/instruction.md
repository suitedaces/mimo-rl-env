I want a `DummyAuthorizer` class for configuring virtual FTP users entirely in memory. It should be used as `auth = DummyAuthorizer()`, then `auth.add_user(username, password, homedir, perm='elr', msg_login='Login successful.', msg_quit='Goodbye.')`, `auth.add_anonymous(homedir, **kwargs)`, `auth.remove_user(username)`, `auth.override_perm(username, directory, perm, recursive=False)`, and query methods such as `validate_authentication(username, password, handler)`, `get_home_dir(username)`, `has_user(username)`, `has_perm(username, perm, path=None)`, `get_perms(username)`, `get_msg_login(username)`, and `get_msg_quit(username)`.

After `auth.add_user('alice', 'secret', homedir, perm='elr', msg_login='Welcome.', msg_quit='Bye.')`, `auth.has_user('alice')` should be true, `auth.get_home_dir('alice')` should return the real path of `homedir`, `auth.get_perms('alice')` should return `'elr'`, and the login/quit message getters should return `'Welcome.'` and `'Bye.'`. `auth.validate_authentication('alice', 'secret', handler)` should complete without returning a value, while `auth.validate_authentication('alice', 'wrong', handler)` and an unknown username should raise `AuthenticationFailed` with an authentication-failed message. Calling `auth.add_anonymous(homedir)` should create an `anonymous` account with read-only permissions by default, and `validate_authentication('anonymous', any_password, handler)` should accept any password; if anonymous access is not configured, validating `anonymous` should raise `AuthenticationFailed` with an anonymous-access-not-allowed message.

The permission string should accept the FTP permission letters `elradfmwMT`; an unknown permission letter passed to `add_user`, `add_anonymous`, or `override_perm` should raise `ValueError`. Assigning write permissions to `anonymous` should emit a `RuntimeWarning`. `add_user` and `add_anonymous` should raise `ValueError` for a missing home directory and for duplicate users, and `remove_user(username)` should remove the account so later lookups no longer find it.

I also need per-directory permission overrides. `auth.override_perm('alice', subdir, 'w', recursive=True)` should make `auth.has_perm('alice', 'w', subdir)`, files directly inside `subdir`, and nested descendants true while leaving the home directory itself governed by the user's base permissions. With `recursive=False`, the override should apply to the directory itself and files directly inside it, but not nested subdirectories or their contents. Overrides for the home directory itself, paths outside the user's home directory, missing directories, or regular files should raise `ValueError`. The no-op `impersonate_user(username, password)` and `terminate_impersonation(username)` methods should exist so this authorizer can be used anywhere an authorizer object is expected without changing process identity.
