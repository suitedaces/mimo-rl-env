I want `siuba.siu.call(__func, *args, **kwargs)` to adapt ordinary Python callables and siu expressions for use inside `>>` pipelines without calling them immediately. Users should be able to import it with `from siuba.siu import call`, and `call(range)` should create a deferred step so that `1 >> call(range)` returns `range(1)`. Passing `_` explicitly should place the piped value at that argument position: `1 >> call(range, _, 2)` returns `range(1, 2)`, and `1 >> call(range, 2, 3, _)` returns `range(2, 3, 1)`.

The helper should preserve positional and keyword arguments, including siu expressions nested in keyword values: `"," >> call("a,b,c".split, _, maxsplit=1)` returns `["a", "b,c"]`, and `1 >> call("{0}_{1}_{b}".format, _, 2, b=3)` returns `"1_2_3"`. It should also accept a complete siu expression as its only argument, so that `"abc" >> call(_[0].upper())` returns `"A"`. If the first argument is a siu expression but additional positional or keyword arguments are also supplied, `call` should raise `NotImplementedError` instead of trying to guess how to combine them. Constructing the deferred step should not execute the target callable; the callable runs only when the returned step is evaluated with data.
