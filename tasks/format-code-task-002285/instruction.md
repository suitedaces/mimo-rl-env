I want the Go `webp` package to support encoding grayscale Go images to WebP through these public functions: `EncodeGray(w io.Writer, p *image.Gray, c *Config) error` and `EncodeGrayWithProgress(w io.Writer, p *image.Gray, c *Config, progressHook ProgressHook) error`.

For a 1x10 `*image.Gray` gradient encoded with `ConfigPreset(PresetDefault, 100)`, `EncodeGray` should return `nil`, write WebP bytes to the provided writer, and those bytes should report width 1 and height 10 when passed to `GetInfo`. For a 2x2 `*image.Gray` containing values 0, 85, 170, and 255, the function should likewise return `nil` and write a decodable 2x2 WebP image. The input `*image.Gray` pixels, stride, and rectangle must not be mutated; the only intended side effect is writing encoded bytes to the supplied `io.Writer`.

`EncodeGrayWithProgress` should perform the same grayscale encoding while calling the progress hook with integer percentage updates. If the hook returns `true`, encoding should continue and eventually return `nil`; if the hook returns `false`, encoding should abort and return a `*EncodeError` whose `EncodeErrorCode()` is `EncodeErrorCodeVP8EncErrorUserAbort`. If the supplied `*Config` is invalid, both functions should fail before writing a successful image and return the same invalid-configuration error behavior as the other WebP encode entry points.
