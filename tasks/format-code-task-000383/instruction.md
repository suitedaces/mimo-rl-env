When I call `unsubscribe_to_data(**{'55': 'EUR/USD'})`, it should send the same kind of MarketDataRequest to the quote session, but with subscription type disable previous snapshot plus updates (`263=2`). If I omit `55`, the symbol should default to `EUR/USD`; if I provide `264`, `267`, or `265`, those FIX tag options should be reflected in the outbound message. Passing a non-integer value for `264` or `267` should raise `ValueError` and should not send a message.
