I want a pure helper function `parse_mm_uuids(mm_uuids: MultiModalUUIDDict | None) -> MultiModalUUIDItems` available from `vllm.multimodal.parse` for normalizing user-supplied multimodal cache identifiers before prompt processing. When called with `None`, it should return `{}`. When called with `{"image": "hash_cherry"}`, it should return `{"image": ["hash_cherry"]}` so a single UUID string is treated as one item for that modality. When called with `{"image": [None, "hash_stop"], "video": None}`, it should return an equal mapping with the list and `None` values passed through unchanged. Calling it multiple times with the same input should produce equal results, and it should not mutate the caller's input mapping or lists. The helper should have no filesystem, network, or global-state side effects; length and modality validation can be handled by later request-processing code.
