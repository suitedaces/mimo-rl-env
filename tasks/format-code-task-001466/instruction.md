I want autogold to support raw text snapshots for golden-file assertions. The public API should include `type Raw string`, and when I call `autogold.ExpectFile(t, autogold.Raw(contents))`, autogold should compare and update the `.golden` file using `contents` exactly as provided instead of formatting it as a Go literal.

For example, `autogold.ExpectFile(t, autogold.Raw("{\"ok\":true}\n"))` should expect the golden file to contain `{"ok":true}\n` directly, with no surrounding quotes, escaping, Go type wrapper, or automatically added newline. Likewise, `autogold.ExpectFile(t, autogold.Raw("line 1\nline 2"))` should use exactly those two raw lines as the snapshot text. When cleanup mode is active, an empty raw snapshot such as `autogold.ExpectFile(t, autogold.Raw(""))` should remove the corresponding `.golden` file rather than preserving an empty file.
