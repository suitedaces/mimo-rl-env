I want existing `Kor2Vec` and `ContextKor2Vec` objects to train their embedding weights from skip-gram samples through public stateful methods: `Kor2Vec.train(corpus_path=None, model_path=None, sample_path=None, sample_output_path=None, window_size=5, negative_sample_count=5, positive_sample_count=4, batch_size=1024, epochs=10, pre_sequence=False) -> None` and `ContextKor2Vec.train(...) -> None` with the same arguments.

A sampled training file should be UTF-8 text with one tab-separated row per center word: the center word, space-separated positive context words, and space-separated negative words. For example, with `sample_path` pointing to a file containing `안녕\t나는 반가워\t도라에몽 클로바\n`, `Kor2Vec(embed_size=8).train(sample_path=sample_path, model_path=out, positive_sample_count=2, negative_sample_count=2, batch_size=1, epochs=2, pre_sequence=True)` should convert each word into fixed-length character-index tensors, optimize the model with positive-context scores and negative-sample scores, return `None`, and write checkpoints named `<out>.ep0` and `<out>.ep1` using `torch.save`. After the call, the same object should retain the trained parameters so `embedding(...)` and `save(...)` operate on the updated model.

If `sample_path` is not provided, calling `train(corpus_path=corpus, sample_output_path=sampled, ...)` should first create skip-gram samples from `corpus`; if `sample_output_path` is omitted, the sample file path should default to `corpus + ".sampled"`. `window_size`, `negative_sample_count`, and `positive_sample_count` should control sampling and tensor sizes consistently.

`pre_sequence=True` should materialize converted examples when training starts; `pre_sequence=False` should convert rows lazily as batches are read. A missing `sample_path` file should raise `FileNotFoundError` before any checkpoint is written, and a malformed sampled row that does not have center, positive, and negative tab-separated fields should fail rather than silently training on bad data. The same training method should work for `ContextKor2Vec(...)`, updating the contextual model and writing the same epoch-suffixed checkpoints.
