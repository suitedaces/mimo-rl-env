Make bundled Python protocol ZIPs lossless to round-trip and safe to consume. The public `create_bundle()` and `extract_bundle()` helpers currently disagree about valid `BundleContents`: creation flattens nested data names, drops `bundled_python`, and produces an archive that extraction rejects when there are no custom labware definitions. They also accept ambiguous archive paths that can be dangerous when another tool unpacks the ZIP.

Treat every non-directory archive member name as a relative POSIX path before `extract_bundle()` classifies or ignores it. Reject the archive with `RuntimeError` if a member is absolute, Windows-drive-qualified, contains a backslash, contains `.` or `..` path components, or contains an empty interior component. Also reject duplicate member names, comparing Unicode NFC-normalized full paths while remaining case-sensitive. Unicode spelling and case must otherwise be preserved, so names such as `Case.txt` and `case.txt` may coexist.

Make `create_bundle()` validate the complete set of member names it will produce under the same rules before writing. A rejected call with an initially empty output stream must leave that stream empty and raise `RuntimeError`. Validate names generated from labware definitions as well as caller-provided names, and reject any two generated members that collide after NFC normalization.

For valid contents, preserve each bundled-data key's full relative path under `data/` instead of reducing it to a basename, and write every bundled-Python entry as UTF-8 text at its key's relative path. Bundled-Python paths may not replace `protocol.ot2.py` or live under the reserved `data/` or `labware/` roots. An archive with no custom labware is valid and must extract with an empty `bundled_labware` mapping. For UTF-8 protocol text and valid names, creating and then extracting a bundle must reproduce the protocol, labware mapping, data bytes, and Python-source mapping.

Keep the established bundle structure and error behavior around the required root `protocol.ot2.py`, archives with no root files, conflicting labware URIs, and parsing of existing valid bundles.
