I want stateful data-series resampling APIs in `pyalgotrade.dataseries.resampled`: `ResampledBarDataSeries(dataSeries, frequency, maxLen=None)` for OHLCV bars and `ResampledDataSeries(dataSeries, frequency, aggfun, maxLen=None)` for generic values. Each object subscribes to the source data series' new-value event, keeps the current time bucket open, and appends one grouped value to itself when a later source value crosses into the next bucket. `pushLast()` should flush the currently open bucket, and `checkNow(dateTime)` should flush it when `dateTime` no longer belongs to that bucket.

For `ResampledBarDataSeries`, the input must be a `pyalgotrade.dataseries.bards.BarDataSeries`; passing a different data series raises `Exception("dataSeries must be a dataseries.bards.BarDataSeries instance")`. Given second bars at `2011-01-01 01:01:01` with open `2.1`, high `3`, low `1`, close `2`, volume `10`, adjusted close `1`; `2011-01-01 01:01:02` with open `2`, high `3`, low `1`, close `2.3`, volume `10`, adjusted close `2`; and `2011-01-01 01:02:01` with open `2`, high `3`, low `1`, close `2`, volume `10`, adjusted close `2`, a one-minute `ResampledBarDataSeries` should have one completed bar after the third append. That completed bar should be dated `2011-01-01 01:01:00`, use the first open `2.1`, max high `3`, min low `1`, last close `2.3`, summed volume `20`, last adjusted close `2`, and the requested output frequency. After `pushLast()`, it should append the second minute's bar dated `2011-01-01 01:02:00`.

For `ResampledDataSeries`, the `aggfun` receives the list of values collected in a bucket and its return value is appended with the bucket's beginning datetime. For example, wrapping the close-price series from the same three bars with `ResampledDataSeries(closeSeries, bar.Frequency.MINUTE, sum)` should append `4.3` for the first minute after the third source bar arrives, and after `pushLast()` it should append `2` for the second minute. Unsupported resampling frequencies should raise `Exception("Unsupported frequency")` during construction.
