I want an `AttackRoll` class exported from `DnD_battler` and `DnD_battler.dice` for resolving D&D-style weapon attacks. Users should be able to construct it as `AttackRoll(name, ability_die: AbilityDie, damage_dice: Dice, modifier: int = 0)`, preserving the attack `name`, the linked `ability_die`, and the bound `damage_dice` on the instance.

The instance method `attack(enemy_ac: int, advantage: Optional[int] = None, add_ability_to_damage=True, munchkin=False) -> int` should roll the attack against the target armor class and return `0` on a miss or the total damage on a hit. For example, with `ability_die = AbilityDie(bonus=2)`, `damage_dice = Dice(num_faces=[1])`, and `roll = AttackRoll('training sword', ability_die, damage_dice, modifier=3)`, `roll.attack(enemy_ac=100)` should return `0`, while `roll.attack(enemy_ac=-100)` should return `3` because the one-point damage die hits and the ability bonus is added. If `ability_die.temp_modifier = 1`, the same guaranteed hit should return `4`; if `add_ability_to_damage=False`, it should return only the damage die result. When `munchkin=True`, the ability die's proficiency bonus should also be added to hit damage.

Critical hit and fumble state from the linked `AbilityDie` should affect attack resolution: a natural 20 should hit and roll the bound damage dice twice, while a natural 1 should miss. The optional `advantage` argument should be passed through to the hit roll so callers can request advantage or disadvantage without mutating the attack object.

I also need `AttackRoll.parse_attack(name: str, ability_die: AbilityDie, damage_dice, attack_modifier: int) -> AttackRoll` as a convenience constructor. It should accept an existing `Dice`, a dice notation string such as `'2d6+1'`, or an integer face count such as `8`; unsupported damage dice inputs should raise `KeyError`. Finally, `AttackRoll.parse_list_attack(attack: list, ability_die)` should support the legacy list form like `['club', 2, 0, 4]`, creating an attack named `'club'` with attack modifier `2` and a `d4` damage die with bonus `0`.
