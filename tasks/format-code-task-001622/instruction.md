I want an existing `NodeGraph` instance to support file-backed session persistence with `current_session()`, `save_session(file_path)`, `load_session(file_path)`, and `import_session(file_path, clear_undo_stack=True)`. `save_session(file_path)` should strip surrounding whitespace from the path, write the current `serialize_session()` result as JSON to that file using readable indentation, serialize any sets as JSON arrays, and then make `current_session()` return the saved path. For example, after a graph has at least one registered node in it, calling `graph.save_session(' /tmp/layout.json ')` should create `/tmp/layout.json` containing the graph/session JSON and `graph.current_session()` should return `/tmp/layout.json`.

`load_session(file_path)` should strip the path, raise `IOError` with `file does not exist: <path>` when the file is missing, clear the current graph, then read that JSON file into the graph as a fresh session with the undo stack cleared. `import_session(file_path, clear_undo_stack=True)` should also strip and validate the path, read JSON from the file, merge the session data into the existing graph without clearing it first, pass the `clear_undo_stack` option through to the dictionary deserialization step, update `current_session()` to the imported path, and emit `session_changed` with that path. If a JSON file cannot be read or parsed, `import_session` should print a readable `Cannot read data from file.` message and leave the graph unchanged instead of raising from the JSON parser.
